# FemaleAestheticDesignSystem

## 1. Skill 名称
FemaleAestheticDesignSystem（女性向UI/UX设计规范系统）

## 2. 描述
该 Skill 专为前端开发与 UI/UX 设计师提供面向女性用户群体的界面设计准则与代码规范。当智能体在编写前端页面、构建 UI 组件或进行视觉设计时，若目标受众为女性用户，将自动调用此 Skill。它内置了“高级感、温馨阳光、扁平微渐变、灵动微动效”四大核心设计哲学，提供从色彩、排版、卡片组件到交互动效的全套规范，确保生成的界面具备高情绪价值、低认知负荷与极佳的视觉质感。

## 3. 使用时机 (Trigger)
当用户发出以下类型的指令时，智能体应自动激活此 Skill：
- 编写或重构面向女性用户的 APP/Web 前端页面代码。
- 设计女性向产品的 UI 组件（如卡片、按钮、导航栏）。
- 咨询关于“女性向设计”、“高级感”、“温馨风格”、“微渐变”等视觉规范。
- 要求优化现有界面的视觉质感与交互体验。

## 4. 核心设计规范体系 (Design Guidelines)

### 4.1 色彩与情绪规范 (Color & Emotion)
- **主色调选择**：摒弃高饱和度的刺眼色彩。推荐使用低饱和度、高明度的自然色系（如晨曦粉、奶油黄、鼠尾草绿、燕麦色），传递治愈与温馨感。
- **扁平微渐变 (Soft Gradient)**：背景或核心按钮应采用微渐变处理，模拟自然光影（如 160度角的 `linear-gradient`），避免纯色带来的生硬感。
- **色彩心理学**：利用色彩传递情绪价值，例如用暖橘色表示成功/鼓励，用淡蓝色表示宁静/信息提示。

### 4.2 布局与排版规范 (Layout & Typography)
- **呼吸感与留白**：高级感的核心是“克制”。严格执行间距系统，页面左右安全边距建议 `20px`，模块间距建议 `16px-24px`，杜绝信息拥挤。
- **Bento（便当盒）布局**：推荐采用大小不一的矩形模块错落组合，打破传统对称网格的死板，提升视觉节奏感与信息传递效率。
- **字体层级**：采用清晰的无衬线字体，通过字重（Weight）和颜色深浅（而非仅靠字号大小）来建立信息层级，降低阅读疲劳。

### 4.3 核心组件规范 (Component Styling)
- **大圆角设计**：全局组件（卡片、按钮、输入框）统一采用偏大的圆角（如 `16px-24px`），消除尖锐直角带来的视觉攻击性。
- **玻璃拟态卡片 (Glassmorphism)**：摒弃粗重的实线边框。采用半透明白底（如 `rgba(255,255,255,0.75)`）配合背景模糊（`backdrop-filter: blur`）与弥散阴影（如粉色/暖色系的 `box-shadow`），营造卡片轻盈悬浮的质感。

### 4.4 交互与微动效规范 (Micro-interactions)
- **丝滑过渡**：所有状态切换（Hover、Active、页面跳转）必须使用带有缓动曲线（`cubic-bezier` 或 `ease-in-out`）的过渡动画，时长控制在 `0.3s` 左右。
- **情感化反馈**：
  - **按压反馈**：点击时轻微缩小（如 `scale(0.96)`），模拟真实的物理触感。
  - **悬浮反馈**：鼠标悬停时向上微平移（如 `translateY(-4px)`）并加深阴影，增强空间层次。
  - **焦点引导**：核心激活状态（如底部导航选中态）可加入轻微的呼吸光晕或脉冲动画（`pulse`），提供安全感与引导性。
- **克制原则**：动效必须轻量且仅在关键时刻触发，坚决抵制过度炫技导致界面杂乱或性能卡顿。

## 5. 输出要求
当智能体根据此 Skill 编写前端代码或输出设计方案时，必须：
1. **代码自包含**：输出的 HTML/CSS 代码应内嵌样式与关键帧动画，无需外部依赖即可预览。
2. **规范注释**：在关键 CSS 属性旁添加注释，说明其遵循了哪条女性向设计规范（如 `/* 玻璃拟态与弥散阴影 */`）。
3. **响应式考量**：代码结构需具备良好的弹性，确保在不同屏幕尺寸下依然保持留白与排版的优雅。

## 6. 使用示例

**用户指令：**
> 帮我写一个女性美妆社区的帖子详情页，要求有高级感，排版要温馨一点。

**智能体执行逻辑：**
1. 识别到“女性”、“高级感”、“温馨”关键词，触发 `FemaleAestheticDesignSystem`。
2. 采用奶油色/淡粉色微渐变作为页面底色。
3. 帖子正文区域使用大圆角、无实线边框的悬浮卡片承载。
4. 点赞、收藏按钮配置按压缩小与悬浮上浮的 `0.3s` 微动效。
5. 输出包含完整样式与注释的 HTML/CSS 代码片段。
