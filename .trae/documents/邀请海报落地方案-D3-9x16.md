# 邀请海报落地 — 方案 D3（9:16 · 固定内置装饰图 · 随机文案）

## Context（背景）

用户对「邀请有礼」分享海报做了多轮设计选型，最终选定 **方案 D3 布局**，并确定了三条硬性要求：

1. **画布改 9:16（300×533.33）** —— 现有 `InvitePosterCard` 是 3:4（300×400），需改为竖版，与新设计稿一致（也符合项目记忆「邀请海报 9:16」铁律）。
2. **顶部图片装饰带用固定内置图** —— 导出超稳，不受网络影响（用已打包的 `assets/images/templates/golden_landscape.jpg`）。
3. **随机文案每次打开时随机一次** —— 从 4 条候选（①③④⑤）中随机，预览与导出一致，下次打开再变。

落地目标是重写 `InvitePosterCard`，在**不改变调用方契约**的前提下，复用现有 `PosterGenerator` 导出能力，并同步更新单元测试。

## 现状（已探明）

- `lumira_app_flutter/lib/features/invite/widgets/invite_poster_card.dart`：`InvitePosterCard`（StatelessWidget，3:4，`PosterCanvas(300×400)`）。当前文案 `'随手拍，亦成作品'` / `'一套模板 · 一键出片'` 等，与 D3 新设计不符。
- 调用方 `invite_poster_sheet.dart` 的 `showInvitePosterSheet(code, tokens)` 用 `PosterGenerator.showPoster(plainContentKey: ...)` 捕获卡片级内容导出（注释说明「严格 3:4（1080×1440）」——此注释需随改 9:16 更新）。
- 入口 `profile_invite_page.dart` 的 `_generateInviteCard()` 调用 `showInvitePosterSheet`，**不用改**。
- 可复用组件（`lib/shared/widgets/poster/poster_common.dart`）：
  - `PosterCanvas(width, height, padding, borderRadius, borderColor)`
  - 样式辅助 `posterSerif` / `posterPlain` / `posterSerifEn`
  - `PosterBrandOnPhoto`（叠图上的品牌行，白色+阴影，适合顶带图上）
  - `PosterQr(data, size, padding, radius, borderColor)`（高分辨率矢量二维码，导出可靠）
  - `PosterTitle` / `PosterKicker` / `PosterRule` / `PosterDivider`
  - `PosterPalette`（surface/gold/goldDeep/ink/text2/text3/line）
  - `PosterBrandFoot`
- 资源：`golden_landscape.jpg` 已随 `assets/images/templates/` 打包。

## D3 布局内容（按设计稿）

自上而下（9:16 画布 300×533，padding 约 20/24）：

1. **顶部图片装饰带**（约 150px，满宽 `Image.asset` + `Fit.cover`）：
   - 右下/底部加一条**金色→透明渐变压暗**（遮罩），叠 `PosterBrandOnPhoto`（LUMIRA + 如画）于左上。
2. **标题区**：衬线大标题 `随手一拍，亦成作品`（`posterSerif(28)`，`em`/金色字体 RichText 强调 `亦成作品`）。
3. **双栏对开**（`Row`）：
   - 左栏：三痛点，每条 `• ＋ 要点＋金色小注`（调参太麻烦/模板已调好；构图不会/打开即好看；摆姿难题/照着剪影）。
   - 右栏：三条功能卡（套上模板/一键出片；多款风格/随手挑；剪影跟摆/照做就行），窄圆角卡，`surfaceAlt` 底 + `line` 细边。
4. **留白区（居中）**：情绪文案主句（单行，`posterSerif`）+ 金线 + 副句（`posterPlain(9, text3)`）。
5. **奖励 + 二维码**（底部分隔线）：左 `新人礼 ＋30 积分 双方同得`，右二维码 + 邀请码 `code`。
6. **底部积分小字**（`posterPlain(7, text3)` 居中）：
   `积分用于解锁付费模板：双方各 +30，首次绑定邀请码并完拍一张到账`。

## 随机文案

在 `InvitePosterCard` 内改为 **StatefulWidget**，`initState` 用 `Random` 选一条索引存入 state；build 读 state 渲染。候选（主句/副句 4 组，对应 HTML 的 ①③④⑤）：

| 主句 | 副句 |
|---|---|
| 套上模板，一键就出片 | 不会拍，也能记录下最想留住的美好 |
| 不用学、不用调，套上模板就出片 | 一按快门，美好随手可留存 |
| 关键时刻，套模板一键出片 | 再瞬间的美好，也不怕拍不住 |
| 套上模板一键出片，拍照本就这么简单 | 你的照片，也配被好好记录 |

> 每次「生成邀请卡片」打开 Sheet 时 `InvitePosterCard` 重建 → `initState` 重新随机 → 预览/导出一致，下次打开才变。

## 复用与约束

- 所有样式用 `PosterPalette` 常量，**不引入 App 主题色**（分享海报是导出品牌资产，符合项目铁律「分享海报固定品牌色板」）。
- 顶带渐变遮罩 `Colors.black/PosterPalette.gold` **叠加在图上**，属跨风格合法的「叠加视觉」例外。
- 箭头/圆点只有 `PosterRule`、金色小圆点，无 emoji。
- 解密注意：`PosterCanvas` 用 `height` 参数固定竖版，无需动 `posterFixedHeight`。
