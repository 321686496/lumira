内置水印重做 · 预览 v1

按成片真实比例渲染（基准照片 900×1200 竖构图），坐标语义与 WatermarkRenderer 完全一致： 锚点 = x·基准矩形宽 + 基准矩形.left、y·基准矩形高 + 基准矩形.top， 文字再施加 offsetY = -0.85×行高、水平偏移按对齐方式取 0 / -w/2 / -w， 字号 = fontSize × 基准矩形宽。

本版修掉的三件事：① 基准矩形三处不统一（缩略图忽略画框、编辑页基准矩形高 1.18×照片、成片白板矩形左移 padLeft）→ 统一为一个布局函数； ② 6 款预置排版重做（间距、层级、对称性、去掉会裁切的 ┌┐└┘ 字符拼角）； ③ 文字描边 / 光晕可调（新增 shadowOutline 深色描边宽度 + shadowBlur 柔光半径，均相对字号；默认 0 / 0.08 时与旧实现逐像素一致。预置用 shadowOutline:0.07，给白字一圈紧贴字面的深色描边 —— 亮底上压得住，且不加任何底色块）。

A · 拍立得：问题复现与修复
缩略图（管理页网格 150px）是问题最明显的地方 —— 现状实现完全不处理画框、忽略 space，
日期 y:0.5 直接落到整个预览区垂直正中，也就是你看到的「图片中间」。
B · 6 款预置重做
每款给 4 个视角：成片（深色照片）· 缩略图·网格（150px）· 缩略图·列表（92×120）· 浅色照片（把同一张图提亮 2.15× 检验白字可读性）。
C · 坐标约定说明
供实现对齐用
统一布局函数输出（输入：照片宽高 + WatermarkFrame）：
photoRect = (padLeft, padTop, photoW, photoH)　·　 cardRect = (0, 0, photoW+padLeft+padRight, photoH+padTop+padBottom)　·　 plateRect = (0, photoRect.bottom, cardRect.width, padBottom)
基准矩形选择：element.space == frame → plateRect；否则 → photoRect；plateRect 不可用（非拍立得 / 无白板）时回退 photoRect。
缩略图：几何完全走同一布局函数（含白边/白板/内描边），仅对字号加「下限 5 显示像素、上限显示宽的 16%」的可读性夹取 —— 夹取必须在显示像素上做（现有实现按卡片坐标夹取，小尺寸下会把文字放大到互相重叠）。
编辑页：同样走该函数，并把文字垂直偏移从「-fontSize」改为「-实际行高×0.85」，与成片 WYSIWYG。
