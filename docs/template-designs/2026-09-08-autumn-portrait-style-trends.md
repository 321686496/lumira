## 一、2026 热门人像风格（通用趋势）

| 风格             | 核心特征                           | 依据                                                   |
| -------------- | ------------------------------ | ---------------------------------------------------- |
| 情绪真实 / 原生感     | 拒绝过度 P 图，保留真实皮肤纹理与情绪，抓拍而非摆拍    | Getty「authentic moments」搜索三年增 +81%、「real people」+76% |
| 电影感 Cinematic  | 从圈层进入主流商业风格第一名，侧逆光、氛围叙事        | Revell Photography 2026 趋势榜首                         |
| 胶片 / 模拟复古      | 颗粒、柔化、轻微瑕疵，强调「经得起时间」的记忆感       | DIY Photography：模拟美学将爆发                              |
| 叙事 / 纪实人像      | 用系列图讲身份、情绪与故事，多为身份驱动           | VSI：含叙事图片互动高 57%                                     |
| 大胆高饱和回归        | 回暖，告别米色/低饱和长期统治，强调色彩、硬闪、Y2K 感  | BehindMud 2026                                       |
| 画家风格 Painterly | 有颗粒感又偏「平」，道具化、高创意布景，对抗 AI 千篇一律 | 代表：Szilveszter Makó                                  |
| 日系原生胶片         | 素颜 + 生活化抓拍，逆光柔光、胶片颗粒、烟火气叙事     | 增田彩来（Instagram 六月新增中文关注 4w+）                         |

### 共性趋势速记

1. **低饱和统治审美** → 松弛、耐看、真实感
2. **素颜原生**成为新流量密码 → 不磨皮、原图直出、抓拍感
3. **新中式国风**彻底翻红 → 已成人像风格第一，差异化最强
4. **情绪 > 美感** → 从精致摆拍转向「抓拍感 / 情绪纪实」

## 二、秋季热门人像风格（季节专项）

| 秋季风格        | 画面要点                                | 适配 App 方向   |
| ----------- | ----------------------------------- | ----------- |
| 大地色系复古      | 米/卡其/焦糖/红棕格纹 + 阔腿裤，侧逆光金边轮廓，下午 3-5 点 | 复古港风、法式慵懒   |
| 暖调针织居家 Cozy | 堆叠针织围巾、围炉咖啡、窗边柔光，书/茶杯道具，低饱和奶油调      | 日系清新、奶油感    |
| 逆光枫叶肖像      | 背景红叶墙、逆光发丝轮廓光（rim light）、点测光人脸      | 氛围感人像、电影感   |
| 枫叶互动抓拍      | 捧叶抛洒、手持单叶、落叶小径行走，构图留白               | 生活纪实、少女感    |
| 蓝调时刻 / 薄雾晨曦 | 日出前后冷调雾气、深景层，电影感基调更浓                | 情绪纪实、电影感    |
| 新中式 × 秋色    | 改良旗袍/盘扣 + 秋景光影，低饱和东方色系，留白构图         | 新中式国风（当前第一） |

### 秋季用光 / 穿搭通用要点

- **用光窗口**：上午 9-11 点、下午 3-5 点；侧/逆光勾勒发丝金色轮廓光；避开正午顶光

- **秋季穿搭色系**：大地暖色（奶油、芥末、酒红、森林绿、焦糖、棕）；避免亮红/亮橙以免融进红叶

- **氛围道具**：针织围巾、咖啡/热茶（冷气出蒸汽）、复古皮质手提箱、手写信、落叶

## 三、落地建议

秋季最能体现「穿搭 × 拍摄 × 氛围」的组合，建议优先落地以下 3 个差异化模板：

1. **逆光枫叶肖像** —— 踩中「电影感 + 氛围感」，季节贴合度最高
2. **暖调针织居家** —— 踩中「原生感 + 低饱和 + 舒适氛围」，室内外皆可
3. **大地色复古（港风 / 法式）** —— 踩中「复古 + 叙事」，秋季天然适配

三者同时覆盖 2026「原生感、电影感、低饱和」三大主流。
