信息类型设备型号、操作系统版本、设备标识符

是否必需是（用户主动选择时）

二、第三方 SDK 目录

为实现以下功能，我们接入了第三方 SDK。相关 SDK 仅在您使用对应功能时收集必要信息，且均在本地处理，不收集第三方共享数据：

SDK 目录更新日期2026-08-24

相机与相册

SDK 名称camerawesome / image_picker（含 HarmonyOS 适配组件）
提供方开源组件与兼容层
使用目的拍摄照片、从相册选取图片
收集的信息仅当您主动操作时，处理图片数据于本地

扫码识别

SDK 名称qr_code_scanner
提供方开源组件
使用目的扫描二维码完成模板导入或账号恢复
收集的信息相机画面仅在本地解析

系统分享

SDK 名称share_plus
提供方开源组件
使用目的调用系统分享面板分享作品或模板
收集的信息不收集，分享在系统层面完成

本地存储

SDK 名称sqflite（设备本地数据库）
提供方开源组件
使用目的在设备本地存储作品、模板、偏好等数据
收集的信息数据仅存于设备本地，不对外上传

统计分析 SDK

SDK 名称基础统计服务
提供方本应用运营方自建
使用目的崩溃日志与使用统计
收集的信息设备型号、操作系统版本、崩溃日志

图像处理能力

SDK 名称本地图像处理组件
提供方本应用内置组件
使用目的照片编辑、滤镜与模板合成
收集的信息不收集，均在设备本地完成
