# 首页运营视角重构设计（问题 1/3/4/5/6）

> 日期：2026-09-15
> 范围：Flutter 端（`lumira_app_flutter/`）首页整体结构
> 后端：**零改动**（不涉及 API / 表结构 / 埋点通道）

## 背景与目标

首页当前结构经运营视角评审，存在 6 个问题，本次修复其中 5 个（问题 2「运营位条件过宽」本次不动，单独跟进）：

1. **HeroCard 占首屏 ~40%**：资讯型内容占据最贵曝光位，转化核心「最近模板流」被推到首屏折线以下；
3. **三个横向卡片流视觉同构**：最近模板 / 场景推荐 / 继续创作同为 130×248 竖卡横向滚动，视觉疲劳、运营素材区分度低；
4. **成长条沉底**：连续天数/经验是留存抓手，却放页底几乎无曝光，且 4 项平铺、可读性差；
5. **运营位曝光太短**：4 条 Banner 统一 5s 自动轮播，运营位 slot 0 只有 5s 曝光；
6. **首页无搜索入口**：丢失最高意图流量与运营投放位。

本次目标：**重构首页信息层级**，让转化核心（模板流）进入首屏、三个内容块视觉可辨、留存抓手（成长条）上移、运营位曝光提效、补齐搜索入口。

## 非目标 / 范围界定

- **不做**问题 2（运营位条件收窄：积分阈值 + 访问间隔），本次不触碰 `operation_banners.dart` 条件逻辑；
- **不改** Banner 数据模型、运营条目配置、埋点通道（曝光/点击 `trackingId` 链路保持不变）；
- **不改** HeroCard 的内容数据（今日灵感文案、推荐模板逻辑），只改排版与样式；
- **不改** 4 套 UI 风格 / 主题色机制，所有改动必须风格自适应（见下方铁律）。

## 一、新页面结构（布局顺序）

```
LumiraNav（品牌标题 + 扫码/通知/兑换）
├─ ① 搜索胶囊（新增，导航正下方）
├─ ② HomeBanner（运营位 + 个性化轮播，slot0 逻辑不变）
├─ ③ QuickActions（拍摄/发现/灵感/相册）
├─ ④ GrowthStrip（上移 ← 原页底）
├─ ⑤ HeroCard（压缩版，内容不变）
├─ ⑥ 最近使用模板（提前）
├─ ⑦ 场景推荐（改沉浸式卡片形态）
└─ ⑧ 继续创作（改 2 列照片网格）
```

**首屏预期**：搜索胶囊 + Banner + 入口 + 成长条 + 压缩 HeroCard + 模板流标题首行均落入首屏（约 774dp 可用高度），模板流从「屏下」提回「屏内」。

## 二、问题 1：HeroCard 压缩（内容不变，排版 + 样式）

**目标**：高度 ~320 → ~210，信息密度不变，视觉更紧凑。

- 移除 hero-deco 装饰半圆（占位大、无信息量）；
- 垂直 padding 28 → 16；描述文案 maxLines 2 → 1；
- 内嵌推荐模板卡缩略图 72×96 → 56×72，文字区同步压缩；
- 天气行并入日期行右侧（同一行小字），不再独占一行；
- CTA 按钮高度略降；
- 4 风格（neumorphic/flat/glass/female）× 主题下必须风格自适应，不引入任何硬编码颜色/阴影。

## 三、问题 3：三个内容块视觉差异化

| 区块 | 现状 | 改为 |
|---|---|---|
| 最近模板 | 130×248 竖卡横向流 | 保持现状（作为「标准参照」）|
| 场景推荐 | 130×248 竖卡横向流 | **沉浸式封面卡**：宽 ~150、封面铺满整卡 + 场景名/氛围叠在图上（下方渐变遮罩 + 文字），与白底卡彻底区分 |
| 继续创作 | 130×248 竖卡横向流 | **2 列照片网格**（复用 3:4 竖图，`GridView` + 懒加载）|

- 三块视觉语言：**白底卡（模板）/ 沉浸图卡（场景）/ 照片网格（作品）**，一眼可辨；
- 沉浸卡与网格均走 `appThemeProvider` + `uiStyleProvider` 派生样式（渐变遮罩属「叠在照片上」合法例外，规则见 AGENTS.md 第 1 条）。

## 四、问题 4：成长条上移 + 精简

- 位置：QuickActions 正下方（原页底移除）；
- 4 项 → 3 项：**连续天数（放大突出）+ 作品 + 经验**，去掉收藏项（留存激励弱）；
- 连续天数数字加大 + 品牌色强调，作为留存 KPI 主视觉；
- 卡片样式继续风格自适应。

## 五、问题 5：运营位曝光时长

- **轮播间隔按类型自适应**：当前页是运营位（`BannerType.operation`）时停留 **10s**，个性化位保持 5s；
- 实现：`_restartTimer` 按当前 banner 的 `type` 选间隔；手动滑动后重计时逻辑不变；
- 备选（不采用）：运营位不参与自动轮播——4 条混排实现复杂，手动滑过后行为不统一。

## 六、问题 6：搜索胶囊

- 位置：LumiraNav 下方、Banner 上方，圆角胶囊（仿 App Store）；
- 左搜索图标 + 占位文案「搜索模板 / 场景 / 拍摄教程」（静态，后续可运营配置）；
- 点击 → `RouteNames.search`（全局搜索页已存在，直接复用，**不新建页面**）。

## 八、验收标准

1. **首屏**：774dp 内可见搜索胶囊 + Banner + 入口 + 成长条 + HeroCard + 模板流标题；
2. **HeroCard**：内容字段一个不丢（标题/日期/描述/推荐模板/CTA/天气），高度 ≤ ~210，4 风格 × 8 主题不变形；
3. **差异化**：三块内容视觉可辨（白底卡 / 沉浸卡 / 照片网格）；继续创作网格点击行为与现状一致（进详情/再拍）；
4. **成长条**：位于 QuickActions 下方，仅 3 项，连续天数突出；
5. **运营位**：运营位停留 10s、个性化 5s，手动滑动后计时重置正确；
6. **搜索胶囊**：点击进入 `/search` 全局搜索页；
7. **回归**：Banner 曝光/点击埋点、`trackingId` 链路、邀请/积分/解锁路由不受影响；无新增硬编码颜色/阴影。
