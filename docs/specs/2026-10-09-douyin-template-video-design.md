- 状态：设计已获用户批准，实施中

## 1. 参考片风格定位

参考《VibeCoding大赏｜喵呜企画》（19s）：Rotato 样机 + 纯UI展示流，无真人口播，节奏快、镜头以样机为中心轻推近/滑入，文案大字在留白区，结尾带话题标签。本项目完全复刻该骨架，仅替换内容为「如画 Lumira」拍摄主线。

## 2. 技术规格

- 画幅 9:16 竖屏 1080×1920，30fps，总时长约 20s（600帧）
- 蹭话题：#vibecoding大赏 #ai新星计划
- 双交付：静音版 + BGM版（AI合成轻快 pluck 琶音 + 轻鼓点）
- 制作管线：方案A —— HTML 单文件固定画布 + 时间轴纯函数 `setT(t)`；URL 参数 `?t=秒` 定格渲染（无 rAF），预览模式自动播放；msedge headless 逐帧截图 600 张 → ffmpeg `h264 yuv420p` 合成
- 文案红线：禁止站外平台名与下载引导词（小红书限流教训复用）

## 5. 视觉规范

- 暖白奶油底 `#F7F2EA` 系 + 金色细线 + 衬线中文标题（沿用邀请海报品牌语言）
