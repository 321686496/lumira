第二轮与第一轮的差异

第一轮（A 收藏册 / B 明信片）：对称结构、自上而下线性编排、金线外框 + 四角金标、规整的 3+2 照片网格。

第二轮 C · 拾光星图：去掉外框与网格——照片作为「星」不对称散落在暖白纸面上，金色虚线星座连线把已点亮的碎片串成图， 未收集的空位是「虚位以待」的星位描点；右侧竖排衬线标题如卷轴落款；进度用「点亮了几颗星」表达。收集行为被重新讲成「把光挂上夜空」。

第二轮 D · 光影手记：整体是杂志内页的编辑排版——左对齐衬线大标题 + 大字号页码数字（3/5） + 日期区间， 照片按 2+3 错落拼版、日期标签压图（半透明深底白字），底部「手记」段落用金色侧线引出，邀请句做成上下细线的编辑部按语。收集行为被重新讲成「给生活记页码」。

共同保留：暖白 + 金 + 衬线的品牌基因、3:4 竖版、每枚碎片的中文章节编号（壹贰叁肆伍）、空位悬念文案、 「我晒我的，换你晒你的」晒图邀请、无二维码纯社交定位。
