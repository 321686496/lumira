V7 怎么同时解决「多张 + 比例不一 + 好看」

① 需求边界确认：单枚碎片最多收集 5 张，数量 ≤5，因此海报全部展示而非精选。这正好落在求解器能力内， 不会因"量太大放不下"而崩塌。
② 解决"乱"的钥匙 = 衬板：照片比例不一，导致照片墙四周边缘天然参差，浮在白底上就像随手拼贴—— 正是你吐槽的"照片墙乱"来源。对策是把照片墙整体放进一枚金色发丝线内框 + 浅米色衬板（surface-alt）里， 内边距 14px。参差边缘被衬板"收住"，视觉上读作一幅装裱的画廊作品，而不是零散照片，质感立刻高级。
③ 计算层不变：同一套 solveRows 等高自适应求解器，枚举行分组、行内宽度 = 行高 × 原生比例， 任意比例组合零裁切、零变形；间距放宽到 11px，照片去阴影只留极淡内描边。
④ 数量自适应：1–5 张都能给出稳定好看的构图——1 张时衬板内即一大幅，5 张时衬板内密而不乱； 点「随机换一批」可无限验证任意组合。

Flutter 落地提示：求解器 `solveRows` 约 80 行 Dart 与 V5 一致可复用；照片比例异步解析复用 `_resolveAspectRatio。新增的只是衬板容器（发丝边框 + 衬底 + 内边距），是一个静态 Widget，成本低。
