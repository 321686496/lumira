零裁切方案 · 与前两轮差异

① 混合比例零裁切（本轮核心）：照片区采用「等高自适应画廊」——同一行照片等高、宽度按各自原生比例分配 （实现上按 flex-grow = 宽高比 分配，格子天然与照片同比例，contain 即满幅贴合）。 16:9 / 1:1 / 9:16 / 4:3 / 3:4 五档比例混排，全部完整入册、零裁切、零变形。每张照片带比例标签（01 · 16:9）明示系统。
空位不预设形状：因为下一张照片比例未知，空位不再画固定比例的虚线框，而用文字占位（「比例随缘，拍到啥算啥」）—— 收集到新照片后整版自动重排（reflow），任何比例都接得住。
Flutter 落地提示：现有 fragment_poster_generator.dart 的 galleryStrip（等高画廊带）已是这套逻辑，本轮设计可直接复用其照片区实现，成本低。

② 排版全新：E 把海报做成一张「收银小票」——锯齿撕边、虚线分隔、点线对账栏、条码流水号（纯装饰，不编码任何信息）； F 做成一张「冲印选片单」——胶片齿孔条、帧号标签、油性笔手绘圈选（这张绝了）、勾选框选片结果、撕线取件凭证。 进度表达也随之更新：E 用「入账 / 结清」，F 用「已选 / 全要」。与第一轮（外框印章册页）、第二轮（星图连线 / 杂志页码）完全不同。

③ 文案接地气：全程说人话——「不吹不黑」「先晒为敬」「评论区蹲一个同好」「连拍二十张挑的」「这波可以吹一年」， 晒的是成绩单也是心态，让刷到的人会心一笑、愿意跟一条「我也拍过」。
