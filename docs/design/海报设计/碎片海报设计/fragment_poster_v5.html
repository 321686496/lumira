本轮修正了什么

① 回归分享海报本体：砍掉「小票 / 选片单」的猎奇形态——那是在炫排版创意，不是在帮用户晒照片。 本轮海报结构回归经典：品牌 → 情绪标题 → 照片墙（主角） → 晒图邀请 → 进度落款，暖白 + 金 + 衬线，安静衬照片。

② 没有固定槽位 · 求解式自适应排版：照片区只有一个固定高度的「画框」，内部怎么排由算法现场计算—— 枚举所有行分组方案（≤5 张照片只有 16 种分法），每种算出各行的等高值，选「能装下且最填满」的那一种；行内每张照片的宽度 = 行高 × 自身原生比例， 所以格子天然等于照片比例，1:1 / 3:4 / 4:3 / 9:16 / 16:9 任意组合、任意数量，全部完整露出、零裁切、零变形。 演示覆盖：全 1:1、全 16:9、全 9:16（极端竖图）、五档混合、单张——并且可点按钮无限随机重掷。
空位只用文字条表达（「还差 N 枚 · 拍到好光马上补上」），不画任何预设形状的虚线框；收集到新照片后整个区域重新求解重排，任何比例都接得住。

③ Flutter 落地成本低：同一套求解器约 80 行 Dart（枚举行分组 + 等高计算），照片真实宽高比的异步解析 fragment_poster_generator.dart 里已有现成的 _resolveAspectRatio 可直接复用；现有 galleryStrip 只处理固定 3+2 分行，替换为求解器即可。
