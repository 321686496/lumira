# 个人中心主页 + 编辑资料页 UI 重设计

日期：2026-08-20
范围：`lumira_app_flutter/lib/features/profile/pages/profile_page.dart` 与 `profile_edit_page.dart`

## 背景与目标

用户反馈个人中心主页“排版与布局太丑”：8 张卡片纵向平铺、头部 Hero 过于呆板居中、多个重复「图标+标题行」模式；编辑资料页的头像选择区为 2×4 重网格套娃卡片，显得呆板。

已与用户确认方向：

- 主页面参考主流 App（微信/小红书式）个人页：**顶部信息条 + 数据条 + 宫格内容 + 分组列表**。
- 「我的内容」用宫格图标。
- 头像选择改由 **popup 弹出层** 承载，编辑页正文不再内嵌网格。

## 主页面 ProfilePage 布局（自上而下）

1. **头部信息条**（替换原 `_HeroCard` 居中 Hero）
   - 左：64dp 圆形头像（点击看大图，右下角编辑角标 → 编辑页）
   - 右：名字（Noto Serif 20dp w600）+ 下一行「等级徽章 / 个性签名」小结
   - 右上角：设置齿轮入口
   - 偏好摘要卡 `_ProfilePrefsCard` 并入头部逻辑：未填时头部显示「完善摄影偏好 ›」链接；已填时折叠为一行短标签。
2. **数据条**：作品 / 模板 / 收藏，3 列等分 + 细分隔线（原 `_StatsCard` 精简）。
3. **我的内容（宫格）**：我的相册 / 拍摄日记 / 探店足迹 / 我的精选集（原 `_ContentCard` 宫格化保留）。
4. **碎片收集**：单卡，标题 + 「已集 x/y」右侧，下方 4 项进度（原 `_FragmentCard` 精简）。
5. **快捷工具 2×2 宫格**：成长中心 / 我的组合 / 邀请有礼 / 摄影美学院（原 `_QuickActionsRow`）。
6. **常用功能分组列表**：我的模板 / 场景管理 / 导入模板 / 我的奖励 / 我的积分 / 兑换码 / 关于如画（原 `_MenuCard` 精简，移除「设置」项移入头部）。
7. **底部反馈**：浅色单行入口（原 `_FeedbackEntryCard` 降权）。

所有卡片统一沿用 `NeuCard` / `appThemeProvider` / `uiStyleProvider`，遵守「样式随设置、禁止风格混搭、新拟态浮层取向」规范，不硬编码主题色。

## 编辑资料页 ProfileEditPage（改造）

1. **基本信息区（顶部）**：左侧当前头像（72dp 圆形 + 编辑角标，点击弹出选择器）+ 右侧用户名输入框 + 「随机换一个」。
2. **摄影偏好区**：性别 / 喜欢拍什么 / 拍摄烦恼 / 预期 / 常用场景 / 水平 / 频率。
3. 底部：保存按钮。

## 头像选择器 = popup 弹出层（新增）

- 组件：`_AvatarSheet` 或独立 widget（ModalBottomSheet，高度自适应，品牌圆角）。
- 顶部：「选择头像」+ 右上关闭。
- 主体：8 个头像网格，选中态 = 品牌色描边环 + 柔和光晕 + 对勾角标；去掉套娃 NeuCard。
- 底部：「上传自定义头像」（复用 `_pickAndUploadAvatar` 逻辑）+「确认」。
- 随 4 风格 × 主题自适应。
