## 1. 品牌策略

### 1.1 核心痛点

普通人不会构图、不会摆姿、不懂参数、不会后期 → 拍不出好照片。

### 1.2 产品功能隐喻

把专业摄影师的经验"翻译"成取景框里看得见的引导。本质：**让看不见的专业眼光，变成看得见的画面引导**。

### 1.3 品牌核心隐喻

**取景框（Frame）+ 光（Lumi）= 框住光，即成画面**

- 取景框 = 专业构图的可视化边界
- 光 = 暖意 / 灵感 / 引导
- 两者融合 = 用专业引导，拍出有温度的好照片

### 1.4 品牌调性

| 维度 | 描述 |
|---|---|
| 品牌角色 | 个人随身工具 |
| 情感 | 安静、专注、即刻 |
| 视觉密度 | 极简留白、稀疏 |
| 主色调 | 米白为主 + 暖金点缀 |
| 字体感 | 衬线大字 + 留白 |
| LOGO 形态 | 单框 + 斜光（独立工具） |

## 3. LOGO 设计

### 3.1 设计方法论

按 brandkit 方法论：先确定核心隐喻，再用「产品动作 + 隐喻融合 + 负空间」组合，最后给出构造几何。

核心隐喻：取景框（专业构图的边界）+ 光（暖意 / 灵感 / 引导）= 框住光即成画面。

### 3.2 LOGO 符号概念

**一个取景框，框住一束斜射进来的光。**

```
  ┌───────────┐
  │  ╱        │     ← 取景框（正方形，圆角 12%）
  │ ╱         │     ← 一道斜光从左上角射入框内
  │╱          │     ← 光用渐变光斑 / 留白表达
  │     ●     │     ← 框右下角一个小光点（焦点 / 快门）
  └───────────┘
       Lumira
```

### 3.3 几何构造逻辑

| 元素 | 规格 |
|---|---|
| 主体 | 80×80 正方形，圆角 12%（编辑式精致感，不胶囊化） |
| 取景角标 | 四角的 L 形取景标记（致敬相机取景器），仅在四角出现，不全封闭 |
| 斜光 | 从左上到右下的对角光带，宽度 12%，柔光渐变（暖金色 → 透明） |
| 焦点光点 | 右下区域一个 Ø8 实心圆点（暖金色），象征"按下快门的瞬间" |
| 负空间 | 光带穿过框内时，框线在光带上"断开"，形成负空间错位感 |

### 3.4 设计理由

- 取景角标（L 形）= 通用摄影语言，大众一秒识别"拍照"
- 斜光 = "如画"的光感，温暖、有方向性、有故事感
- 单一焦点 = "聚焦好画面"的产品价值
- 负空间错位 = 高端品牌常用手法，避免廉价感

### 3.5 LOGO 变体

| 变体 | 说明 | 用途 |
|---|---|---|
| 主标 | 取景框符号 + "Lumira" 文字（衬线字，间距宽松） | 品牌标准使用 |
| 符号标 | 仅取景框符号 | App Icon、Favicon |
| 文字标 | 仅 "Lumira" 衬线字 | 品牌延展 |
| 单色版 | 纯墨色 #1A1A1A | 深色背景 |
| 反白版 | 纯米白 #FAF7F2 | 深色场景 |

### 3.6 App Icon 规范

| 属性 | 值 |
|---|---|
| 背景 | 暖米白 #FAF7F2 纯色 |
| 符号 | 取景框 + 斜光（暖金 #C9A96E） |
| 圆角 | iOS 自动 squircle |
| 内边距 | 符号占图标 65% |
| 文字 | App Icon 不含文字 |

### 3.7 LOGO 使用禁忌

- 不拉伸变形、不旋转
- 不改变描边粗细
- 不加投影 / 发光 / 渐变
- 不放在低对比度背景上
- 不与其他符号叠加
- 不改色（仅允许指定单色版）

## 4. 主题配色系统

按 minimalist-ui 原则：色彩是稀缺资源，仅用于语义与点缀；不用渐变、不用重彩背景、不用霓虹色。

### 4.1 配色方案 —— 米白暖金墨

**调性**：安静、精致、东方留白。米白为主，暖金为点缀，墨色为骨。

| 角色 | 色名 | HEX | RGB | 用途 |
|---|---|---|---|---|
| 画布底色 | 暖米白 | `#FAF7F2` | 250,247,242 | 全局背景 |
| 卡片表面 | 纯净白 | `#FFFFFF` | 255,255,255 | 卡片 / 输入框 |
| 次级表面 | 浅米灰 | `#F2EEE6` | 242,238,230 | 分组背景 / 选中态 |
| 主文字 | 浓墨 | `#1A1A1A` | 26,26,26 | 标题 / 正文 |
| 次文字 | 中墨 | `#5C5852` | 92,88,82 | 辅助说明 |
| 弱文字 | 浅墨 | `#9C9690` | 156,150,144 | 占位 / 禁用 |
| 分隔线 | 极浅米线 | `#EAE5DC` | 234,229,220 | 1px 分隔 |
| **品牌主色** | **暖金** | `#C9A96E` | 201,169,110 | LOGO / CTA / 选中 |
| 品牌辅色 | 深暖金 | `#A88550` | 168,133,80 | 按下态 / 强调 |
| 警示 | 赤茶 | `#B85450` | 184,84,80 | 删除 / 错误 |
| 成功 | 苔绿 | `#7A8B5C` | 122,139,92 | 完成 / 成功 |

**点缀色（仅用于标签 / 徽章）**：

- 淡金底 `#F5EDDB` / 文字 `#8C7340`
- 淡赤底 `#F5E3E0` / 文字 `#9F3F3A`
- 淡绿底 `#EBEEE2` / 文字 `#566340`

**色板分布比例**：

```
背景区  米白/白  ████████████████████  70%
文字区  墨色系   ████████              20%
品牌色  暖金    ██                     8%
点缀色  淡彩    █                      2%
```

### 4.2 深色模式

| 角色 | 色值 |
|---|---|
| 画布 | `#1C1A17`（暖墨） |
| 卡片 | `#262320` |
| 主文字 | `#F2EEE6` |
| 品牌色 | `#D4B57A`（亮暖金） |

### 4.3 色彩使用纪律

1. **大面积禁用品牌色**：暖金仅用于 CTA、选中态、LOGO，绝不大面积铺色块。
2. **不用渐变**：除非 LOGO 内部光带（允许单色渐变到透明）。
3. **不用重阴影**：阴影不透明度 < 0.05。
4. **不用胶囊大容器**：按钮圆角 4-6px，卡片圆角 12px，仅小徽章用 pill。
5. **正文不用纯黑**：用 #1A1A1A，保留暖意。
6. **分隔线只用 1px 极浅色**。

## 5. 字体系统

按 minimalist-ui 原则：禁用 Inter / Roboto / Open Sans。

### 5.1 字体选择

| 角色 | 字体 | 用途 |
|---|---|---|
| **中文正文** | 思源黑体 / 苹方 | UI 正文、按钮、列表 |
| **中文标题** | 思源宋体 / 苹方 Heavy | 大标题、品牌字 |
| **英文正文** | SF Pro Display / Helvetica Neue | UI 英文 |
| **英文标题** | Newsreader / Playfair Display | 英文大标题 |
| **数字 / 代码** | SF Mono / JetBrains Mono | 参数、数值、EXIF |

### 5.2 字号层级 —— 衬线主导，留白多

| 层级 | 字号 | 字重 | 行高 | 字间距 | 字体 |
|---|---|---|---|---|---|
| 品牌大标题 | 36px | Semibold | 1.1 | -0.03em | 思源宋体 / Newsreader |
| 页面标题 | 24px | Medium | 1.2 | -0.02em | 思源宋体 / Newsreader |
| 区块标题 | 18px | Medium | 1.3 | -0.01em | 思源黑体 |
| 正文 | 15px | Regular | 1.6 | 0 | 思源黑体 / SF Pro |
| 辅助文字 | 13px | Regular | 1.5 | 0 | 思源黑体 |
| 标签 / 徽章 | 11px | Medium | 1.4 | +0.05em | SF Pro |
| 参数数值 | 13px | Regular | 1.4 | 0 | SF Mono |

### 5.3 字体使用纪律

1. **不用纯黑文字**：用 #1A1A1A
2. **标题用紧字距**：letter-spacing -0.02em ~ -0.03em
3. **正文用宽行高**：line-height 1.6
4. **数字用等宽字**
5. **不混用过多字重**：每屏最多 3 种
6. **标签全大写**

## 6. 页面风格

### 6.1 东方编辑式留白

**风格关键词**：静谧、专注、留白、衬线、即刻

**核心设计语言**：

- **大留白**：页面边距 24-32px，区块间距 48-64px，呼吸感极强
- **衬线主导**：标题用宋体 / Newsreader，正文用黑体，对比强烈
- **稀疏排版**：每屏信息密度低，仅突出当下操作
- **细线分隔**：1px 极浅米线，不用卡片堆叠
- **无阴影**：组件零阴影，靠分隔线和留白分层
- **暖金点缀**：仅选中态 / CTA 用暖金色，其余克制

**视觉灵感**：Kinfolk 杂志、无印良品手册、Apple Books 阅读器

**典型页面氛围**：

打开 APP，米白背景映入眼帘，顶部一行宋体大标题"如画"，下方一行小字"框住光，皆成画卷"。中间是大片留白，仅一张最近拍摄的作品预览图，下方一个暖金色细描边的圆形快门按钮。整个界面像翻开一本摄影画册。

### 6.2 底部 Tab（3 个）

- 拍摄（首页，居中放大圆形快门按钮）
- 模板
- 我的

> 仅 3 个 Tab，对应"拍 → 修 → 管"的极简流程。

## 9. 图标系统

### 9.1 图标风格

- 风格：Phosphor Icons Bold 或 Radix UI Icons（细而有力）
- 描边：1.5px
- 尺寸：16 / 20 / 24 / 32px
- 颜色：跟随当前文字色，选中态用暖金
- 不用：Lucide、Feather、Heroicons

### 9.2 自定义图标

- 模板图标（方框 + 叠图）

## 10. 动效规范（极简）

- 页面切换：150ms 淡入淡出
- 按钮按下：scale(0.98)，100ms
- 列表项进入：translateY(8px) + opacity 0→1，400ms
- 取景器叠图显隐：200ms 透明度过渡

**性能纪律**：仅动画 transform 与 opacity，不触发 layout。
