> 文档版本：v1.0
> 创建日期：2026-07-03
> 文档类型：产品设计规格（PRD）
> 工程方案：方案 B —— 单机版与联网版为两个独立 uni-app 工程

---

## 0. 文档说明

本文档定义「好拍 PhotoPost」两款独立产品形态的完整需求：

- **好拍·单机版（PhotoPost Lite）**：完全离线、纯净无网络依赖、无 AI 的随身摄影工具。
- **好拍·联网版（PhotoPost Pro）**：联网的模板市场 + 作品社区 + 云端 AI 增强的摄影服务平台。

两款产品通过统一的 `.pptpl` 拍摄模板文件格式互通。

---

## 1. 产品概述

### 1.1 产品名称

- 单机版：好拍·单机版（PhotoPost Lite）
- 联网版：好拍·联网版（PhotoPost Pro）

### 1.2 一句话定位

让普通人拍出专业级好照片的随身摄影助理——通过"拍摄模板"将专业摄影师的构图、姿势、参数、后期经验固化为可复用方案，小白套用即拍，进阶可二次创作。

### 1.3 解决的痛点

普通人拍照常遇到的痛点：

- 不会构图，不知道主体放哪、画面如何安排
- 不会摆姿势，拍出来僵硬、不自然
- 不懂相机参数，曝光/白平衡/对焦把握不准
- 不会后期，调色/磨皮/裁剪无从下手
- 请专业摄影师成本高、不即时

### 1.4 解决方案

把专业摄影师的经验结构化为「拍摄模板」，一个模板包含：构图叠图、姿势参考轮廓、相机参数预设、场景拍摄指南、后期调优参数包。用户套用模板即获得取景框内的可视引导 + 一键应用的参数，从"拍"到"修"形成完整闭环。

### 1.5 产品双形态对比

| 维度 | 单机版（Lite） | 联网版（Pro） |
|---|---|---|
| 网络依赖 | 完全离线（零网络权限） | 联网 |
| AI 能力 | 无 | 云端 AI 增强 |
| 核心能力 | 本地内置模板 + 代码算法调优 | 模板市场 + 社区 + 云端 AI |
| 模板流通 | 文件导出/导入分享 | 平台发布/下载/互动 |
| 账户体系 | 无（本地设备 ID） | 手机/微信/Apple 账户 |
| 商业模式 | 免费 + 模板付费（分成） | 免费 + 模板付费（分成）+ 广告 |
| 工程形态 | 独立 uni-app 工程 | 独立 uni-app 工程 |

### 1.6 核心价值主张

把"专业摄影师脑子里的经验"变成"小白取景框里看得见的引导线 + 一键应用的参数"。

## 2. 用户角色与典型场景

### 2.1 用户角色

| 角色 | 单机版 | 联网版 | 核心诉求 |
|---|---|---|---|
| 摄影小白（C 端消费者） | ✓ | ✓ | 不懂参数也能拍出好看的照片 |
| 进阶爱好者 | ✓ | ✓ | 学习构图/姿势，套用专业模板提升出片 |
| 专业摄影师/创作者（PGC） | ✓（本地创作） | ✓ | 发布模板变现、积累粉丝、打造个人品牌 |
| 平台运营 | — | ✓ | 运营挑战赛、推荐位、内容审核 |

### 2.2 典型场景

1. **旅行打卡**：小白到了网红机位，打开 APP 选"旅行人像"模板 → 取景框叠加构图线 + 姿势轮廓 → 按提示设置参数 → 拍摄 → 一键套用后期参数包 → 成片。
2. **探店自拍**：选"咖啡馆半身"模板 → 姿势叠图引导 → 拍后调色参数包自动应用 → 导出分享。
3. **创作者变现（联网版）**：摄影师发布"日落逆光剪影"模板 → 用户付费下载 → 作者获分成。
4. **离线分享**：单机版用户 A 把自制模板导出为 `.pptpl` 文件发给用户 B → B 导入使用。
5. **社区挑战（联网版）**：参与"#夏日海边人像"挑战 → 提交作品 → 社区投票 → 上榜获曝光。

## 3. 模板体系（两端共享核心概念）

### 3.1 模板定义

「拍摄模板」是一份可复用的"拍摄方案包"，是产品的最小价值单元，也是两端互通的桥梁。

### 3.2 模板文件格式（`.pptpl`，两端统一）

```json
{
  "meta": {
    "id": "tmpl_xxx",
    "name": "日落逆光剪影",
    "author": "creator_id_or_local_device_id",
    "version": "1.0.0",
    "category": "人像",
    "tags": ["逆光", "剪影", "日落"],
    "price": 0,
    "cover": "url_or_local_path",
    "description": "适合黄昏海边/山顶的逆光人像剪影"
  },
  "composition": {
    "overlayType": "rule_of_thirds | grid | leading_lines | custom",
    "overlayResource": "svg_or_png_path",
    "subjectFrame": { "x": 0.3, "y": 0.2, "w": 0.4, "h": 0.6 },
    "opacity": 0.5
  },
  "pose": {
    "referenceImage": "transparent_png_path",
    "position": { "x": 0.5, "y": 0.5 },
    "scale": 1.0,
    "rotation": 0
  },
  "camera": {
    "exposureCompensation": -0.7,
    "isoMode": "auto | manual",
    "iso": 100,
    "shutterSpeed": "1/200",
    "whiteBalance": "daylight | cloudy | auto",
    "focusMode": "auto | manual",
    "filterPreset": "warm",
    "lensSuggestion": "main | wide | tele"
  },
  "sceneGuide": {
    "lightDirection": "backlight",
    "shootingDistance": "3-5m",
    "background": "天空/水面，避免杂物",
    "props": ["宽檐帽", "纱巾"],
    "tips": "让模特侧身，轮廓更清晰"
  },
  "postProcess": {
    "cropRatio": "3:4",
    "color": {
      "brightness": 0.1,
      "contrast": 0.15,
      "saturation": -0.1,
      "temperature": 0.2,
      "tint": 0.0
    },
    "smoothStrength": 0.3,
    "sharpen": 0.2,
    "vignette": 0.3,
    "grain": 0.1,
    "lut": "warm_sunset.cube"
  }
}
```

### 3.3 模板流通路径

- **单机版**：内置精选 → 本地创建/编辑 → 导出 `.pptpl` 文件 → 系统分享 → 其他用户导入
- **联网版**：创作者发布到市场 → 用户浏览/付费下载 → 评论/点赞/收藏 → 也可导出 `.pptpl` 到单机版
- **互通性**：
  - 联网版下载的模板可导出给单机版使用
  - 单机版导出的模板可上传到联网版市场（需创作者账号）
  - 两端模板引擎共用同一份 TS 类型定义与序列化/反序列化逻辑（独立 npm 包 `@photopost/template-spec`）

### 3.4 模板兼容性

模板含 `version` 字段，引擎做向后兼容处理：加载时校验版本，旧版本模板自动迁移或提示升级。

### 3.5 模板创建工具

两端都内置「模板编辑器」：

- 上传姿势参考图（透明 PNG）
- 绘制构图叠图（路径/九宫格/三分法/自定义形状）
- 调试相机参数
- 调试后期参数（实时预览效果）
- 预览 → 保存为 `.pptpl`

单机版编辑结果仅存本地，可导出分享；联网版编辑器支持云端草稿与多端同步。

## 4. 好拍·单机版 功能设计

### 4.1 功能架构

```
单机版
├── 拍摄模块（核心）
│   ├── 自定义相机取景器（叠加构图线/姿势轮廓/参数提示）
│   ├── 模板套用拍摄（加载模板→实时叠图→参数引导→拍摄）
│   ├── 自由拍摄（无模板，仅基础相机）
│   └── 拍摄参数面板（手动调节曝光/白平衡/对焦等）
├── 后期模块（本地代码算法）
│   ├── 模板后期一键应用（套用 postProcess 参数包）
│   ├── 手动调整（裁剪/调色/磨皮/锐化/滤镜）
│   ├── EXIF 读写与参数还原
│   └── 导出（分辨率/水印/格式）
├── 模板模块
│   ├── 模板库（内置精选 + 已导入）
│   ├── 模板编辑器（创建/编辑/调试）
│   ├── 模板导出（.pptpl 文件，系统分享）
│   └── 模板导入（从文件/相册/分享接收）
├── 我的相册（本地照片管理，按模板/时间/场景分类）
└── 设置（无账户体系，纯本地偏好）
```

### 4.2 核心拍摄流程（关键路径）

```
选模板 → 进取景器 → [实时叠图：构图线+姿势轮廓+主体框]
       → 顶部提示：光线方向/距离/镜头
       → 参数引导：显示模板建议参数，用户可"一键应用"或手动调
       → 对齐检测（代码算法：主体是否落入框内/水平线是否水平）
       → 拍摄 → 进入后期 → 一键套用 postProcess → 微调 → 保存/分享
```

### 4.3 实时叠图实现

基于 uni-app 的 `camera` 组件 + 自定义叠加层（nvue/原生插件）渲染半透明图层。姿势轮廓与构图线作为半透明图层覆盖在取景器上，支持透明度调节与显示/隐藏切换。

### 4.4 对齐检测（纯代码算法，非 AI）

- **水平线检测**：基于陀螺仪/加速度计传感器数据判断手机水平状态。
- **主体框对齐**：基于边缘检测/肤色检测的轻量 OpenCV 算法（本地运行），提示"主体偏左/偏右/偏上/偏下"。
- **范围**：仅做简单色彩/边缘区域占比判断，不做人脸识别（避免引入 AI 模型）。

### 4.5 本地后期算法（代码调优，无 AI）

| 功能 | 算法实现 |
|---|---|
| 调色（亮度/对比度/饱和度/色温/色调） | 像素级 LUT/矩阵变换，基于查找表 |
| 裁剪/旋转 | Canvas 像素重采样 |
| 磨皮 | 保边滤波（双边滤波）+ 肤色掩膜 |
| 锐化 | Unsharp Masking |
| 暗角/颗粒 | 径向渐变叠加 / 噪点生成 |
| 滤镜 | 颜色查找表（LUT `.cube` 文件） |

> **明确排除**：单机版**不包含**瘦脸、大眼、五官精修等人脸相关功能（这些依赖人脸关键点检测，归入联网版云端 AI）。单机版仅保留调色/裁剪/磨皮/锐化/暗角/颗粒/滤镜。

### 4.6 模板编辑器（创作者工具）

- 入口：我的 → 模板编辑器
- 能力：上传姿势参考图（透明 PNG）→ 绘制构图叠图（路径/九宫格/三分法）→ 调试相机参数 → 调试后期参数 → 预览效果 → 保存为 `.pptpl`
- 单机版编辑结果仅存本地，可导出分享

### 4.7 单机版非功能性约束

- **零网络权限**：manifest 中关闭所有网络权限，安装包不包含任何网络/上传代码（可审计）。
- **无账户体系**：无登录注册，本地唯一设备 ID 用于模板作者标识。
- **离线性能**：相机启动 < 1s，叠图渲染 < 50ms/帧，后期处理 < 2s（1080P）。
- **包体**：目标 < 40MB（内置精选模板 + OpenCV 轻量库 + LUT 资源）。
- **兼容性**：iOS 12+ / Android 7+。

## 5. 好拍·联网版 功能设计

### 5.1 功能架构

```
联网版
├── 拍摄模块（继承单机版能力 + 云端 AI 增强）
│   ├── 模板套用拍摄（同单机版）
│   ├── AI 实时辅助（云端）：智能场景识别、构图评分、最佳拍摄时机提示
│   └── AI 人像增强（云端）：智能美颜、背景虚化、人像分割
├── 后期模块（本地算法 + 云端 AI）
│   ├── 本地算法后期（同单机版 + 瘦脸等 AI 人像功能）
│   ├── 云端 AI 后期：智能修图、一键大片调色、AI 抠图换背景
│   └── 云端渲染队列（高清/复杂任务异步处理）
├── 模板市场（核心）
│   ├── 模板浏览（分类/榜单/搜索/标签/推荐流）
│   ├── 模板详情（预览/作者/价格/评价/用量）
│   ├── 购买/下载/收藏/使用
│   └── 模板上传（创作者发布、审核、定价、版本更新）
├── 作品社区
│   ├── 作品广场（瀑布流/分类/话题）
│   ├── 作品发布（带模板来源标注，可点击跳转同款模板）
│   ├── 互动（点赞/评论/收藏/分享/关注作者）
│   └── 挑战赛（官方/UGC 话题、参赛、投票、榜单、奖励）
├── 创作者中心
│   ├── 数据看板（下载量/收入/粉丝/作品表现）
│   ├── 收益提现（模板分成）
│   ├── 粉丝管理/消息通知
│   └── 创作者认证（专业资质审核）
├── 账户与支付
│   ├── 注册登录（手机/微信/Apple）
│   ├── 钱包（充值/消费/分成余额）
│   ├── 订单管理
│   └── 会员体系（可选，订阅解锁部分权益）
└── 设置（推送/隐私/缓存/关于）
```

### 5.2 云端 AI 能力清单（联网版独有）

| AI 能力 | 用途 | 触发时机 |
|---|---|---|
| 场景识别 | 识别拍摄场景（人像/风景/美食/夜景），推荐匹配模板 | 拍摄前/取景器实时 |
| 构图评分 | 实时评估当前画面构图，0-100 分 + 改进建议 | 取景器实时 |
| 人像分割 | 背景虚化/换背景 | 后期 |
| 人脸关键点 | 智能美颜/瘦脸/五官精修 | 后期 |
| 智能修图 | 一键调色/画质增强/去瑕疵 | 后期 |
| 姿态识别 | 评估拍摄对象姿势与模板姿势的匹配度 | 拍摄中（可选） |

**实现策略**：AI 能力封装在云端，APP 通过 API 调用。重型任务（如高清 AI 修图）走异步渲染队列，完成后推送通知。

### 5.3 模板市场机制

**模板生命周期**：创作者编辑 → 提交审核 → 上架 → 用户购买/下载 → 评价反馈 → 版本迭代 → 下架。

**审核机制**：机器初筛（违禁词/版权图）+ 人工复审（内容质量/原创性）。

**定价与分成**：

- 创作者可设免费或付费（1-999 元档位，平台抽成 30%）
- 平台精选模板可官方补贴/买断
- 分成按实际成交结算，T+15 打款

**分发维度**：分类（人像/风景/美食/夜景/旅行/亲子...）、榜单（热门/新作/好评/本周精选）、标签、搜索、个性化推荐流。

### 5.4 作品社区与挑战赛

**作品发布**：用户发布成片时自动标注所用模板，其他用户点击"拍同款"直接跳转该模板，形成"作品 → 模板"转化闭环。

**挑战赛**：

- 官方发起主题挑战（如"#夏日海边人像"），设定模板范围或自由创作
- 用户参赛提交作品，社区投票 + 评委评分
- 榜单展示，奖励（流量曝光/模板免费券/创作者分成加成/实物奖品）

**社区治理**：举报/敏感图识别/水军防控/创作者原创保护。

### 5.5 创作者生态

- **入驻**：实名认证 + 作品审核 → 创作者身份
- **成长体系**：新手/进阶/签约摄影师，等级对应流量倾斜与分成比例
- **变现**：模板付费分成 + 挑战赛奖金 + 未来可扩展"付费课程/约拍"

### 5.6 联网版非功能性需求

- **账户安全**：手机/微信/Apple 登录，JWT 鉴权，敏感操作二次验证。
- **支付安全**：对接微信/支付宝/Apple Pay，对账与风控。
- **内容合规**：上传图审核（涉黄/涉政/版权），UGC 实时巡检。
- **性能**：市场列表首屏 < 1.5s，模板下载 < 3s，AI 接口 P95 < 3s。
- **可扩展**：微服务化（用户/模板/社区/支付/AI/通知），支持横向扩容。
- **兼容性**：iOS 12+ / Android 7+。

## 6. 技术架构

### 6.1 整体技术选型

| 层 | 单机版 | 联网版 |
|---|---|---|
| 前端框架 | uni-app (Vue3 + TS) | uni-app (Vue3 + TS) |
| 相机/图像 | uni-app camera 组件 + 原生插件（原生相机/OpenGL 渲染） | 同左 + 云端 AI SDK |
| 本地算法 | OpenCV.js / 原生 C++ 插件（LUT/保边滤波/锐化） | 同左 |
| 后端 | 无 | Node.js (NestJS) + 微服务 |
| 数据库 | SQLite（本地模板库/相册） | PostgreSQL + Redis + OSS |
| AI 服务 | 无 | Python (FastAPI) + ONNX/TensorFlow Serving |
| 存储 | 本地文件系统 | 阿里云 OSS + CDN |
| 部署 | — | Docker + K8s |

### 6.2 单机版架构

```
[UI 层 Vue3]
   ↓
[业务逻辑层] 拍摄管理 / 后期引擎 / 模板引擎 / 相册管理
   ↓
[核心服务层]
   ├── 相机服务（原生插件：取景 + 叠图渲染 + 参数控制）
   ├── 图像处理引擎（原生 C++/OpenCV：LUT/滤波/锐化/裁剪）
   ├── 模板引擎（模板加载/解析/应用/序列化 .pptpl）
   └── 本地存储（SQLite + 文件系统）
   ↓
[平台层] iOS/Android 原生能力（传感器/相册/分享）
```

**关键点**：

- 相机叠图需原生插件实现高性能渲染（uni-app 原生组件 cover-view 性能有限，复杂叠图需 nvue/原生插件）。
- 图像处理走原生 C++ 保证性能。
- 整个工程不含任何网络请求代码与权限声明。

### 6.3 联网版架构（后端微服务）

```
[APP 端] ──HTTPS/WSS──→ [API 网关]
                          ├── 用户服务（注册/登录/鉴权/创作者认证）
                          ├── 模板服务（市场/搜索/下载/审核/版本）
                          ├── 社区服务（作品/互动/挑战赛/消息）
                          ├── 支付服务（订单/钱包/分成/提现）
                          ├── AI 服务（场景识别/构图评分/人像/修图）
                          ├── 推送服务（消息/通知）
                          └── 内容安全服务（审核/风控）
                                  ↓
                    [数据层] PostgreSQL / Redis / OSS / ES（搜索）
                                  ↓
                    [基础设施] K8s + 监控（Prometheus）+ 日志（ELK）
```

### 6.4 模板文件互通规范

`.pptpl` 为两端统一的 JSON 格式文件（见第 3.2 节结构）。两端模板引擎共用同一份 TS 类型定义与序列化/反序列化逻辑（独立 npm 包 `@photopost/template-spec`），确保：

- 单机版导出的 `.pptpl` 可被联网版导入并发布
- 联网版下载的 `.pptpl` 可导出到单机版使用
- 版本兼容：模板含 `version` 字段，引擎做向后兼容处理

## 11. 风险与开放问题

| 风险/问题 | 说明 | 应对 |

## 附录 A：术语表

- **模板（Template / `.pptpl`）**：一份可复用的拍摄方案包，包含构图叠图、姿势参考、相机参数、场景指南、后期参数。
- **叠图（Overlay）**：取景器上覆盖的半透明引导图层（构图线/姿势轮廓/主体框）。
- **LUT（Look-Up Table）**：颜色查找表，用于实现滤镜与调色。
- **PGC**：专业生产内容（Professional Generated Content）。
- **EXIF**：图像文件元数据，记录相机参数等信息。
