# 如画 → 框景 命名变更设计

> 文档版本：v1.0
> 创建日期：2026-08-03
> 文档类型：品牌命名变更设计（Rename Design）
> 触发原因：中文名「如画」在 App Store 被占用
> 英文名不变：Lumira

---

## 1. 背景与目标

- 原中文名「如画」在 App Store 已被占用，无法以上架。
- 英文名 Lumira 保留不变（Lumi=光，-ra 后缀）。
- 目标：新中文名需满足——
  1. 差异化（避免同名占用）；
  2. 与英文名 Lumira 及品牌隐喻「取景框 + 光 = 框住光，即成画面」互文；
  3. 延续「东方编辑式留白」的品牌气质（暖米白、暖金、墨色、衬线标题）。

## 2. 决策过程摘要

| 方向 | 候选 | 结论 |
|---|---|---|
| 画意象（延续） | 入画 / 成画 / 映画 | 大众易懂但差异化弱 |
| 光意象（对齐 Lumira） | 拾光 / 留光 / 光语 / 沐光 | 「拾光」同名摄影 app 泛滥（已核实），排除；其余保留 |
| 传承「如」字 | 如是 | 品牌资产传承最顺，禅意气质匹配，作备选 |
| **框/景意象** | **框景** | **选定：产品隐喻最精准、差异化最强、占用风险低** |

经用户确认，最终选定 **「框景」**。

## 3. 命名系统

| 属性 | 值 |
|---|---|
| 中文名 | 框景 |
| 英文名 | Lumira（不变） |
| App Store 展示名 | 框景 Lumira |
| 副标语 | 「一框一景，皆成画卷」 |
| 拼音 | kuàng jǐng |

### 3.1 字源

「框景」是中国古典园林的核心造景手法——借门、窗、洞等框体，把远景"框"成一幅画。经典诗意表达如杜甫《绝句》"窗含西岭千秋雪"、苏州园林的漏窗借景。

### 3.2 品牌叙事

打开取景框，框住眼前景，即成画卷。产品用专业构图引导用户"框景"——让每个人都能借框取景，拍出如画作品。古代美学 × 现代摄影的合流。

### 3.3 与 Lumira 的互文

- Lumira = 框住**光**（Lumi=光，取景框隐喻）
- 框景 = 框住**景**
- 光与景，同一品牌的两只眼睛：Lumira 负责"光线引导"，框景负责"构图引导"。

### 3.4 气质延续

「框景」二字延续东方美学词汇体系（园林术语、书画语汇），与「东方编辑式留白」的品牌气质、暖米白 + 暖金 + 墨色的配色系统、衬线标题的字体系统完全同频。LOGO（取景框 + 斜光）无需改动——取景框符号本身就是"框"的视觉呈现。

## 4. 应用范围

| 位置 | 变更 |
|---|---|
| lumira-app/src/manifest.json | `"name": "如画"` → `"name": "框景"` |
| 品牌文档（brand spec / PRD） | 「如画」引用 → 「框景」；slogan 同步更新 |
| 页面标题 / splash / 品牌文案 | 全局替换「如画」→「框景」 |
| Flutter 平台配置（iOS/Android 显示名） | 同步更新 |
| App Store Connect | 展示名「框景 Lumira」，提交时最终查重 |

## 5. 风险与注意事项

1. **提交时查重**：App Store 名称占用只能在 App Store Connect 提交时最终确认；「框景」当前未检索到知名同名摄影 app，风险低。
2. **副标语确认**：「一框一景，皆成画卷」为拟定稿；如需保留原 slogan「如你所见，皆成画卷」亦可（两者语义互补，不冲突）。
3. **LOGO 不变**：取景框符号即"框"的视觉表达，无需重新设计。
