## 1. 品牌策略

### 1.1 核心痛点

普通人不会构图、不会摆姿、不懂参数、不会后期 -> 拍不出好照片；专业摄影师有经验但缺少变现平台。

### 1.2 产品功能隐喻

把专业摄影师的经验固化为可交易的"数字模板"，在社区中自由流通。本质：**让创作者的眼光变成可复用的数字资产**。

### 1.3 品牌核心隐喻

**取景框（Frame）+ 光（Lumi）= 框住光，即成画面**

- 取景框 = 专业构图的可视化边界
- 光 = 创作者灵感汇聚的光
- "集" = 众画汇聚成集的社区感

### 1.4 品牌调性

| 维度 | 描述 |
|---|---|
| 品牌角色 | 创作者社区平台 |
| 情感 | 温暖、连接、烟火气 |
| 视觉密度 | 适度丰富、有内容 |
| 主色调 | 暖橙为主 + 米白衬托 |
| 字体感 | 无衬线 + 编辑式排版 |
| LOGO 形态 | 多框 + 光核（社区聚合） |

## 3. LOGO 设计

### 3.1 设计方法论

按 brandkit 方法论：用「隐喻融合 + 负空间」组合构造。

核心隐喻：多个画框交织汇聚，中心形成一颗光核 — "众画汇聚成集"。

### 3.2 LOGO 符号概念

**三个画框交织重叠，中心交汇处形成光核（星形 / 光斑）**。

```
       ╱─────╲
      ╱ ┌───┐ ╲
     ╱  │ ✦ │  ╲    <- 三个画框（左、右、下）交织重叠
    ╱   └───┘   ╲   <- 中心交汇处形成光核（星形 / 光斑）
    └─────────────┘
   Lumira Studio
```

### 3.3 几何构造逻辑

| 元素 | 规格 |
|---|---|
| 主体 | 三个等大的圆角正方形（70x70），分别旋转 0 度、+15 度、-15 度，部分重叠 |
| 中心光核 | 三框重叠区域中心，一个四角星形光斑（暖橙色），象征"社区汇聚的光" |
| 描边处理 | 三框仅描边（2px），重叠处用"加深"混合模式形成自然的层次 |
| 虚实对比 | 中心光核为实心，与外围描边形成"虚框实心"对比 |

### 3.4 设计理由

- 多框交织 = "画集"的"集"字直观外化，社区感强
- 中心光核 = 三个画框共同形成的光，隐喻"社区让每个人的光被看见"
- 与单机版「如画」同源：都用"框 + 光"语言，但单机版是单框（独立工具），联网版是多框（社区聚合）

### 3.5 LOGO 变体

| 变体 | 说明 | 用途 |
|---|---|---|
| 主标 | 三框光核符号 + "Lumira Studio" 文字（无衬线） | 品牌标准使用 |
| 符号标 | 仅三框光核符号 | App Icon、Favicon |
| 文字标 | 仅 "Lumira Studio" 文字 | 品牌延展 |
| 单色版 | 深棕 #2B1F18 | 深色背景 |
| 反白版 | 米白 #FBF8F3 | 深色场景 |

### 3.6 App Icon 规范

| 属性 | 值 |
|---|---|
| 背景 | 暖橙 #E8845C 纯色 |
| 符号 | 三框 + 光核（米白 #FBF8F3） |
| 圆角 | iOS 自动 squircle |
| 内边距 | 符号占图标 65% |
| 文字 | App Icon 不含文字 |

### 3.7 LOGO 使用禁忌

同单机版：不拉伸变形、不改变描边粗细、不加投影/发光/渐变、不改色。

### 4.3 色彩使用纪律

1. **大面积禁用品牌色**：暖橙仅用于 CTA、Tab 选中、LOGO。
2. **不用渐变**。
3. **不用重阴影**。
4. **不用胶囊大容器**：按钮圆角 4-6px，卡片圆角 8px，仅小徽章用 pill。
5. **正文不用纯黑**：用 #2B1F18。
6. **分隔线只用 1px 极浅色**。

## 5. 字体系统

按 minimalist-ui 原则：禁用 Inter / Roboto / Open Sans。

### 5.1 字体选择

| 角色 | 字体 | 用途 |
|---|---|---|
| **中文正文** | 思源黑体 / 苹方 | UI 正文、按钮、列表 |
| **中文标题** | 思源黑体 Heavy | 大标题、品牌字 |
| **英文正文** | SF Pro Display / Helvetica Neue | UI 英文 |
| **数字 / 代码** | SF Mono / JetBrains Mono | 数字数据、EXIF |

### 5.2 字号层级 —— 无衬线主导，bento 排版

| 层级 | 字号 | 字重 | 行高 | 字间距 | 字体 |
|---|---|---|---|---|---|
| 品牌大标题 | 32px | Bold | 1.15 | -0.02em | 思源黑体 Heavy |
| 页面标题 | 22px | Semibold | 1.25 | -0.01em | 思源黑体 |
| 区块标题 | 17px | Semibold | 1.3 | 0 | 思源黑体 |
| 正文 | 14px | Regular | 1.6 | 0 | 思源黑体 / SF Pro |
| 辅助文字 | 12px | Regular | 1.5 | 0 | 思源黑体 |
| 标签 / 徽章 | 10px | Medium | 1.4 | +0.05em | SF Pro |
| 数字数据 | 16px | Semibold | 1.3 | 0 | SF Mono |

### 5.3 字体使用纪律

1. **不用纯黑文字**：用 #2B1F18
2. **标题用紧字距**
3. **正文用宽行高**：line-height 1.6
4. **数字用等宽字**
5. **不混用过多字重**

## 6. 页面风格

### 6.1 暖意编辑式 bento 社区

**风格关键词**：温暖、连接、bento 网格、烟火气、内容驱动

**核心设计语言**：

- **Bento 网格**：不对称 CSS Grid 布局，大小卡片错落
- **1px 边框卡片**：卡片靠 1px 极浅暖线分隔，圆角 8-12px，无阴影
- **内容为王**：作品图占满卡片，文字极简（作者 + 模板名 + 数据）
- **暖橙点缀**：CTA / 选中 / 挑战赛徽章用暖橙
- **数据可视化**：下载量 / 收入 / 排名用 SF Mono 数字
- **微动效**：列表项级联淡入，卡片按下 scale(0.98)

**视觉灵感**：Notion 模板市场、Are.na、小红书编辑流、Apple App Store Today

**典型页面氛围**：

打开 APP，米白底上方是"画集"宋体标题，下方是 bento 网格：左侧大卡片是"本周精选模板"（封面图 + 作者 + 下载量），右侧两个小卡片分别是"挑战赛 #夏日海边"和"新晋创作者"。再往下是热门作品瀑布流，每张作品下方仅显示所用模板名（暖橙小字"拍同款"）。整体像一份精致的摄影周刊。

### 6.2 底部 Tab（5 个）

- 首页（推荐流）
- 模板市场
- 拍摄（居中，可隐藏到底部浮岛）
- 社区
- 我的

## 9. 图标系统

- 风格：Phosphor Icons Bold 或 Radix UI Icons（细而有力）
- 描边：1.5px
- 尺寸：16 / 20 / 24 / 32px
- 颜色：跟随当前文字色，选中态用暖橙
- 不用：Lucide、Feather、Heroicons

---

## 10. 动效规范（适度丰富）

- 列表级联：animation-delay = index x 60ms
- 卡片悬浮：背景色微变 #FFFFFF -> #F9F6F0，200ms
- 点赞：暖橙红心 scale 1->1.3->1，300ms 弹性
- 挑战赛徽章：微旋转 +15 度 -> 0 度，400ms

**性能纪律**：仅动画 transform 与 opacity，不触发 layout。

## 12. 设计纪律与禁忌

### 12.1 必须遵守

- 严格使用第 4 节配色色板
- 严格使用第 5 节字体系统
- 严格使用 8px 栅格间距系统
- 所有卡片用 1px 边框 + 无阴影
- 所有按钮圆角 4-6px，仅小徽章用 pill
- 所有分隔线 1px 极浅色
- 所有数字用等宽字体 SF Mono

### 12.2 严格禁止

- 渐变背景 / 霓虹色 / 玻璃拟态
- 重投影 / 大圆角胶囊容器
- 纯黑正文文字
- 通用图标库（Lucide / Feather / Heroicons）
- 大面积品牌色铺色块
- 拉伸变形 LOGO
- 给 LOGO 加投影 / 发光 / 渐变
- AI 套话文案（"无缝"/"提升"/"释放"/"下一代"/"颠覆"）
