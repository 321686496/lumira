# 「我的内容」四模块优化设计

日期：2026-08-15
范围：Flutter 客户端（`lumira_app_flutter/`），仅本地 DB，无后端改动
状态：设计已获用户确认，待实现

## 背景与目标

用户反馈「我的内容」四个模块（我的相册 / 拍摄日记 / 探店足迹 / 我的精选集）排版与功能需要完善。
从**产品运营**与**顶级 UI** 双视角，目标：

1. 让每个模块拥有独立的「性格」，通过**信息架构 + 版式节奏**体现（不新增配色体系，保证主题切换兼容）
2. 补齐高性价比功能：搜索、统计聚合、筛选、分享、空状态引导、操作反馈
3. 全部改动基于本地数据库（sqflite 离线优先），无后端依赖

## 设计总原则

- 保留全局设计语言：NeuCard / 玻璃背景 / 品牌金令牌（`tokens.brand` 等）/ Noto Serif SC 标题 / FadeUp 入场动画
- 差异化手段 = 模块专属的信息结构与版式节奏，而非新配色
- 分享统一用现有 `share_plus ^7.2.2`
- 无地图 SDK（Harmony 兼容风险），足迹用「分类筛选 + 统计 + 评分」替代地图维度

## 模块一 · 我的相册 —— 性格：「回溯」· 杂志式翻阅

文件：`lib/features/gallery/pages/gallery_page.dart`

1. **时间分组头**：网格按「今天 / 昨天 / 本周 / 更早」分组，组头 Noto Serif SC 小号标题 + 右侧「N 张」
   - 数据：现有 `galleryDao` 查询，按 `createdAt` 分组
2. **顶部概览增强**：张数旁加「本月新增 N」小字
3. **搜索**：顶部信息条加搜索图标 → 滑入搜索框，按场景 / 模板 / 备注关键字实时筛选
   - 数据：新增 GalleryDao 搜索查询（`WHERE` 多字段 `LIKE`）
4. **空状态引导**：加「去拍摄」「导入照片」两个按钮（当前仅文案）
5. **交互反馈**：批量删除/导出后 SnackBar 反馈数量；`RefreshIndicator` 下拉刷新
6. 保留现有长按多选 / 场景筛选

## 模块二 · 拍摄日记 —— 性格：「成长」· 时间轴叙事

文件：`lib/features/gallery/pages/gallery_diary_page.dart`（数据 `gallery_diary_providers.dart`）

1. **打卡卡升级为「本月进度」**：本月打卡天数进度条 + 连续 N 天里程碑徽章（7 / 14 / 30）
   - 数据：复用 `diaryStreakProvider`；新增月度聚合 provider
2. **月度聚合条（4 格）**：本月照片 / 本月打卡天数 / 最常心情 / 常去场景
   - 数据：新增 `diaryMonthlyStatsProvider`（GalleryDao 聚合）
3. **时间线视觉强化**：日期头加左侧金色时间轴引导线与节点圆点，大号日期 + 星期，每日首图放大为横版
4. 月份快速跳转胶囊：本期不做，延后至后续版本

## 模块三 · 探店足迹 —— 性格：「记忆」· 生活手账

文件：`lib/features/checkin/pages/checkin_list_page.dart`

1. **统计卡升级**：足迹数 / 高评店（评分≥4）/ 平均评分（星级展示）/ 今年新增
   - 数据：CheckinDao 聚合
2. **分类筛选 pills**：全部 + 出现过的分类（去重），点击筛选
   - 数据：`CheckinRecord.category`
3. **卡片重排**：封面更大更圆润、名称 + 金色星级 + 分类标签 + 地点 + 时间；评分≥4 加「值得一去」小标签
4. **排序切换**：按时间 / 按评分
5. **分享**：卡片分享按钮 → `share_plus` 分享（名称 + 评分 + 地点 + note + 封面图）

## 模块四 · 我的精选集 —— 性格：「策展」· 画廊作品集

文件：`lib/features/profile/pages/profile_collections_page.dart`

1. **分区组织**：「我的收藏」（manual，前置，新建入口强化）/「系统精选」（auto，附说明「根据你的照片自动生成」）
2. **封面升级**：无封面时用前 4 张照片做 2×2 小型拼贴，封面圆角加大
3. **manual 卡片「⋯」菜单**：编辑 / 删除 / 分享
4. **分享精选集**：`share_plus` 分享名称 + 描述 + 照片数文案
5. **空状态引导**：「去相册选照片创建」

## 成功标准

- 四个页面在默认主题（warmWhite/neumorphic）与至少一个深色主题（ink）下视觉与配色均正常
- 分享功能在目标平台可唤起系统分享面板
- 搜索 / 筛选 / 排序 / 分组数据准确（对照本地 DB 数据）
- `flutter analyze` 与现有测试通过

## 非目标（本期不做）

- 足迹地图视图（无地图 SDK）
- 足迹城市筛选（`place` 为自由文本，非结构化城市字段）
- 相册 AI 智能标签、人脸分组
- 精选集海报导出（后续版本）
