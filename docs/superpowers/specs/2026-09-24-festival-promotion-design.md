# 双节专项推流设计 ·「如画 Lumira」中秋+国庆 Campaign

> v1.0 ｜ 2026-09-24 ｜ 上游文档：`docs/marketing/推流执行手册.md`
> 背景：中秋（9/25-9/27）+ 国庆（10/1-10/7）两节相邻，"请3休13"拼假形成超长出游窗口，大量人出门旅游拍照，是姿势拍照 App 的最佳推广窗口。

---

## 一、已确认决策（2026-09-24 用户拍板）

| 决策点 | 结论 |
|---|---|
| 动作级别 | **内容 + 节日模板上新**（不改 App 功能） |
| 模板上新渠道 | **后台 admin 线上添加**（`POST /admin/templates`，App 从服务器动态拉取，**即时生效无需发版**，保证中秋也能赶上） |
| 模板主题 | **中秋 + 国庆都要** |
| 平台侧重 | **小红书 + 抖音**（符合执行手册"小红书为主 + 抖音放大"） |
| 执行框架 | **方案 A 双节分节奏 Campaign**：中秋急行军（快）+ 国庆主力军（精） |
| 发布口径 | 个人号发布、无官方蓝 V；CTA 统一"应用商店搜索「如画 Lumira」"；商店链接后补 |

---

## 二、方案总览

```
┌─ 中秋急行军（今晚 9/24 ~ 明早 9/25）
│   上新 2 个中秋主题模板 → 今晚 21:00 发 1 篇小红书热点笔记
│
└─ 国庆主力军（9/25 ~ 10/4）
    上新 4 个国庆旅行主题模板（9/28 前完成）
    → 小红书 2 篇 + 抖音 2 条（10/1-10/4 按最佳窗口铺开）
```

统一节日视觉锤：**剪影叠取景器 + 节日元素**（月亮 / 地标 / 出行场景），封面与正文反复出现建立识别度。

## 三、中秋急行军设计（9/24 今晚 ~ 9/25）

### 3.1 时间表

| 时间（北京时间） | 动作 |
|---|---|
| 9/24 18:00-20:00 | 后台新建 2 个中秋模板：姿势图 / 剪影 / 封面走后台 AI 生成管线产出 |
| 9/24 20:00-21:00 | 模板验证：App 真机预览剪影叠加效果、封面与示例图检查、分类归属核对 |
| 9/24 21:00-23:00 | 小红书笔记发布（中秋热点窗口） |

> ⚠️ 中秋模板为"即时上新"性质，AI 生成质量若今晚达不到发布标准，先撤下模板、笔记照发（内容改用通用中秋氛围演示），国庆再补高质量模板。**绝不发布未验证的模板。**

### 3.2 模板设计（2 个，名称具体化）

| 模板名 | 姿势主题 | 场景 / 氛围 | 分类归属（四级） |
|---|---|---|---|
| 「古风赏月·侧身提灯」 | 侧身回眸望月、手拎灯笼 | 夜景 / 庭院，古风氛围 | 一级人像 → 二级古风 → 三级古风人像 → 四级夜景侧拍 |
| 「中秋拜月·双手合十」 | 双手合十对月祈祷 | 夜景 / 露台，静谧氛围 | 一级人像 → 二级古风 → 三级古风人像 → 四级夜景正位 |

**模板必填素材**：cover 封面（必填）、silhouette 剪影（可选）、示例图 / 姿势组、meta（姿势参数 / 构图 / 相机 / 场景 / 后期等）。全部走后台 AI 生成管线 + 人工抽检。

### 3.3 小红书笔记（1 篇）

- **标题方向**：《中秋赏月，朋友圈别再发"游客式合影"了》
- **正文逻辑**：今晚赏月 / 团圆场景痛点（不会摆、只会比耶）→ 演示 2 个新模板剪影（提灯、拜月）→ 教"一个人 + 三脚架 + 剪影对齐"也能出氛围感 → CTA 应用商店搜「如画 Lumira」
- **首图**：剪影叠取景器 + 月亮元素
- **标签**：`#中秋拍照` `#赏月` `#古风写真` `#拍照姿势` `#一个人拍照` `#如画lumira`
- **结尾引导**：评论区互动（"你今晚赏月了吗 / 留下你的中秋照片"）
- **合规**：只讲真实功能，示例图标注"效果示意"，不写"免费"

### 4.2 模板设计（4 个，旅行主题）

|---|---|---|---|

### 4.3 内容设计（小红书 2 篇 + 抖音 2 条）

| 平台 | 篇 / 条 | 方向 | 发布时间 |
|---|---|---|---|
| 小红书 | 第 1 篇 | 新模板种草合集（4 个旅行模板九宫格 + 剪影演示） | 10/2 20:00-23:00 |
| 小红书 | 第 2 篇 | 出游摆姿干货（"打卡照不重样"结合新模板演示） | 10/3 20:00-23:00 |
| 抖音 | 第 1 条 | 模板演示脚本（"假期出片"剪影上身，25-40s 竖屏 9:16） | 10/1 18:00-22:00 |
| 抖音 | 第 2 条 | 情侣出游剧情（"他拍废片 → 剪影拯救"，与第 1 条赛马） | 10/4 18:00-22:00 |

**小红书第 1 篇要点**：标题方向《国庆出行拍照不重样｜4 个旅行模板直接抄》；首图九宫格展示 4 模板效果 + 剪影；正文逐模版演示"人在画面哪个位置"；CTA 统一口径。
**小红书第 2 篇要点**：干货向（构图三招：前景 / 三分法 / 低角度）+ 剪影演示兜底；收藏率导向。
**抖音第 1 条要点**：前 3 秒钩子（废片贴脸）→ 剪影上身 → 成品转场；字幕全程大字；结尾"应用商店搜「如画」"。
**抖音第 2 条要点**：聊天记录吐槽 → 剪影教男朋友 → 前后对比；情绪反转 + 赛马测试。

## 六、执行清单（完成态定义）

1. 中秋模板上新：后台可见 2 个模板，App 真机预览剪影叠加正常、分类正确。
2. 中秋笔记：小红书发布成功，封面 / 正文 / CTA / 标签齐全。
3. 国庆模板上新：后台可见 4 个模板，App 真机预览正常。
4. 国庆内容备齐：小红书 2 篇正文 + 首图、抖音 2 条脚本 + 分镜画面素材，按排期发布。
5. 发布后按执行手册第七节指标（点击率 / 收藏 / 完播率）记录，决定后续动作。

## 七、合规红线（沿用执行手册第八节）

1. 只讲真实功能，不出现不存在的"修图 / 滤镜 / 一键逆天改图"能力。
2. 不写"免费"误导；积分兑换口径与 App 内一致（邀请各 +30 积分 → 解锁付费模板）。
3. 示例图用 App 实拍成品 / 真实模板效果图，标注"效果示意"。
4. 避免绝对化用语（最、第一、顶级）规避审核。
5. 个人号发布，不虚构人设、不冒充官方。
