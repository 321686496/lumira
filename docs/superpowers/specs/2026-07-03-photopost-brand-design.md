## 0. 文档说明

本文档定义两款独立产品的完整品牌与视觉系统：

- **单机版「如画 Lumira」**：完全离线的随身摄影工具
- **联网版「画集 Lumira Studio」**：联网的模板市场 + 作品社区

两款产品共享品牌家族基因（取景框 + 光符号 + 暖色系），但拥有独立的名称、LOGO、配色、字体与页面风格，以体现各自的产品定位。

## 1. 品牌策略

### 1.1 核心痛点

普通人不会构图、不会摆姿、不懂参数、不会后期 → 拍不出好照片。

### 1.2 产品功能隐喻

把专业摄影师的经验"翻译"成取景框里看得见的引导。本质：**让看不见的专业眼光，变成看得见的画面引导**。

### 1.3 品牌核心隐喻

**取景框（Frame）+ 光（Lumi）= 框住光，即成画面**

- 取景框 = 专业构图的可视化边界
- 光 = 暖意 / 灵感 / 引导
- 两者融合 = 用专业引导，拍出有温度的好照片

### 1.4 双产品定位差异化

| 维度 | 如画 Lumira（单机版） | 画集 Lumira Studio（联网版） |
|---|---|---|
| 品牌角色 | 个人随身工具 | 创作者社区平台 |
| 情感 | 安静、专注、即刻 | 温暖、连接、烟火气 |
| 视觉密度 | 极简留白、稀疏 | 适度丰富、有内容 |
| 主色调 | 米白为主 + 暖金点缀 | 暖橙为主 + 米白衬托 |
| 字体感 | 衬线大字 + 留白 | 无衬线 + 编辑式排版 |
| LOGO 形态 | 单框单光（独立） | 多框聚光（社区） |

## 2. 命名系统

### 2.1 命名方案

| 产品 | 单机版 | 联网版 |
|---|---|---|
| 中文名 | 如画 | 画集 |
| 英文名 | Lumira | Lumira Studio |
| 副标语 | "如你所见，皆成画卷" | "万千画卷，集于此处" |
| 含义 | 拍出来就像画一样美；又含"如你所愿"的暖意 | 作品画卷的集合 / 社区 |
| 兼顾性 | 大众易记（美好画面类） | 专业感（Studio 后缀） |

### 2.2 命名设计理由

1. **语义直击**："如画"完美契合"美好画面类"语义，大众一听就懂——拍出来就像画。
2. **兼顾大众与专业**："如画"亲切好记，"Lumira"国际化有质感（Lumi=光，-ra 后缀，造词有高端感）。
3. **暖调契合**：光（Lumi）天然承载暖色调，米白 + 暖金最契合"暖调生活型"。
4. **双产品差异化**：单机"如画"安静内敛（轻工具），联网"画集"温暖连接（社区），同一品牌家族但调性区分明显。

### 2.3 品牌家族关系

```
   单机版「如画」          联网版「画集」
   ┌─────────┐         ┌─────────┐
   │ 单框+光  │  ──同源──→ │ 多框+光核 │
   │ 独立工具  │         │ 社区聚合  │
   └─────────┘         └─────────┘
        共享：取景框语言 + 光符号 + 暖金色系
```

## 3. LOGO 设计

### 3.1 设计方法论

按 brandkit 方法论：先确定核心隐喻，再用「产品动作 + 隐喻融合 + 负空间」组合，最后给出构造几何。

核心隐喻：取景框（专业构图的边界）+ 光（暖意 / 灵感 / 引导）= 框住光即成画面。

### 3.2 单机版 LOGO ——「如画 Lumira」

**符号概念**：一个取景框，框住一束斜射进来的光。

**视觉构造**：

```
  ┌───────────┐
  │  ╱        │     ← 取景框（正方形，圆角 12%）
  │ ╱         │     ← 一道斜光从左上角射入框内
  │╱          │     ← 光用渐变光斑 / 留白表达
  │     ●     │     ← 框右下角一个小光点（焦点 / 快门）
  └───────────┘
       Lumira
```

**几何构造逻辑**：

- 主体：80×80 正方形，圆角 12%（编辑式精致感，不胶囊化）
- 取景角标：四角的 L 形取景标记（致敬相机取景器），仅在四角出现，不全封闭
- 斜光：从左上到右下的对角光带，宽度 12%，柔光渐变（暖金色 → 透明）
- 焦点光点：右下区域一个 Ø8 实心圆点（暖金色），象征"按下快门的瞬间"
- 负空间：光带穿过框内时，框线在光带上"断开"，形成负空间错位感

**设计理由**：

- 取景角标（L 形）= 通用摄影语言，大众一秒识别"拍照"
- 斜光 = "如画"的光感，温暖、有方向性、有故事感
- 单一焦点 = "聚焦好画面"的产品价值
- 负空间错位 = 高端品牌常用手法，避免廉价感

**LOGO 变体**：

- **主标**：取景框符号 + "Lumira" 文字（衬线字，间距宽松）
- **符号标**：仅取景框符号（用于 App Icon、Favicon）
- **文字标**：仅 "Lumira" 衬线字
- **单色版**：纯墨色 #1A1A1A，用于深色背景
- **反白版**：纯米白 #FAF7F2，用于深色场景

### 3.3 联网版 LOGO ——「画集 Lumira Studio」

**符号概念**：多个画框交织汇聚，中心形成一颗光核 —— 隐喻"众画汇聚成集"。

**视觉构造**：

```
       ╱─────╲
      ╱ ┌───┐ ╲
     ╱  │ ✦ │  ╲    ← 三个画框（左、右、下）交织重叠
    ╱   └───┘   ╲   ← 中心交汇处形成光核（星形 / 光斑）
    └─────────────┘
   Lumira Studio
```

**几何构造逻辑**：

- 主体：三个等大的圆角正方形（70×70），分别旋转 0°、+15°、-15°，部分重叠
- 中心光核：三框重叠区域中心，一个四角星形光斑（暖橙色），象征"社区汇聚的光"
- 描边处理：三框仅描边（2px），重叠处用"加深"混合模式形成自然的层次
- 中心光核为实心，与外围描边形成"虚框实心"对比

**设计理由**：

- 多框交织 = "画集"的"集"字直观外化，社区感强
- 中心光核 = 三个画框共同形成的光，隐喻"社区让每个人的光被看见"
- 与单机版同源：都用"框 + 光"语言，但单机版是单框（独立工具），联网版是多框（社区聚合），形成清晰的品牌家族关系

**LOGO 变体**：同单机版（主标 / 符号标 / 单色版 / 反白版）。

### 3.4 App Icon 设计规范

| 规格 | 单机版 | 联网版 |
|---|---|---|
| 背景 | 暖米白 #FAF7F2 纯色 | 暖橙 #E8845C 纯色 |
| 符号 | 取景框 + 斜光（暖金 #C9A96E） | 三框 + 光核（米白 #FAF7F2） |
| 圆角 | iOS 自动 squircle | 同左 |
| 内边距 | 符号占图标 65% | 同左 |
| 无文字 | App Icon 不含文字 | 同左 |

### 3.5 LOGO 使用禁忌

- 不拉伸变形、不旋转
- 不改变描边粗细
- 不加投影 / 发光 / 渐变（保持极简平面）
- 不放在低对比度背景上
- 不与其他符号叠加
- 不改色（仅允许指定单色版）

### 4.4 色彩使用纪律

1. **大面积禁用品牌色**：暖金 / 暖橙仅用于 CTA、选中态、LOGO，绝不大面积铺色块。
2. **不用渐变**：除非 LOGO 内部光带（允许单色渐变到透明），UI 中不使用任何渐变。
3. **不用重阴影**：阴影不透明度 < 0.05，几乎不可见。
4. **不用胶囊大容器**：按钮圆角 4-6px，卡片圆角 8-12px，仅小徽章用 pill。
5. **正文不用纯黑**：用 #1A1A1A（单机）或 #2B1F18（联网），保留暖意。
6. **分隔线只用 1px 极浅色**：不用粗线、不用色块分隔。

## 5. 字体系统

按 minimalist-ui 原则：禁用 Inter / Roboto / Open Sans；用极端字重对比建立编辑式层次。

### 5.1 字体选择

| 角色 | 字体 | 用途 | 理由 |
|---|---|---|---|
| **中文正文** | 思源黑体 / 苹方 | UI 正文、按钮、列表 | 跨平台一致、现代感 |
| **中文标题** | 思源宋体 / 苹方 Heavy | 大标题、品牌字 | 衬线宋体增加东方编辑感 |
| **英文正文** | SF Pro Display / Helvetica Neue | UI 英文 | 系统原生、几何感强 |
| **英文标题** | Newsreader / Playfair Display | 英文大标题 | 衬线、编辑式、有文学感 |
| **数字 / 代码** | SF Mono / JetBrains Mono | 参数、数值、EXIF | 等宽、技术感 |

### 5.2 单机版「如画」字号层级 —— 衬线主导，留白多

| 层级 | 字号 | 字重 | 行高 | 字间距 | 字体 |
|---|---|---|---|---|---|
| 品牌大标题 | 36px | Semibold | 1.1 | -0.03em | 思源宋体 / Newsreader |
| 页面标题 | 24px | Medium | 1.2 | -0.02em | 思源宋体 / Newsreader |
| 区块标题 | 18px | Medium | 1.3 | -0.01em | 思源黑体 |
| 正文 | 15px | Regular | 1.6 | 0 | 思源黑体 / SF Pro |
| 辅助文字 | 13px | Regular | 1.5 | 0 | 思源黑体 |
| 标签 / 徽章 | 11px | Medium | 1.4 | +0.05em (uppercase) | SF Pro |
| 参数数值 | 13px | Regular | 1.4 | 0 | SF Mono |

### 5.3 联网版「画集」字号层级 —— 无衬线主导，bento 排版

| 层级 | 字号 | 字重 | 行高 | 字间距 | 字体 |
|---|---|---|---|---|---|
| 品牌大标题 | 32px | Bold | 1.15 | -0.02em | 思源黑体 Heavy |
| 页面标题 | 22px | Semibold | 1.25 | -0.01em | 思源黑体 |
| 区块标题 | 17px | Semibold | 1.3 | 0 | 思源黑体 |
| 正文 | 14px | Regular | 1.6 | 0 | 思源黑体 / SF Pro |
| 辅助文字 | 12px | Regular | 1.5 | 0 | 思源黑体 |
| 标签 / 徽章 | 10px | Medium | 1.4 | +0.05em | SF Pro |
| 数字数据 | 16px | Semibold | 1.3 | 0 | SF Mono |

### 5.4 字体使用纪律

1. **不用纯黑文字**：单机版 #1A1A1A，联网版 #2B1F18，保留暖意
2. **标题用紧字距**：letter-spacing -0.02em ~ -0.03em
3. **正文用宽行高**：line-height 1.6，呼吸感
4. **数字用等宽字**：相机参数、价格、下载量、EXIF 全部 SF Mono
5. **不混用过多字重**：每屏最多 3 种字重
6. **标签全大写**：英文标签 uppercase + 0.05em 字间距

## 6. 页面风格

### 6.1 单机版「如画」—— 东方编辑式留白

**风格关键词**：静谧、专注、留白、衬线、即刻

**核心设计语言**：

- **大留白**：页面边距 24-32px，区块间距 48-64px，呼吸感极强
- **衬线主导**：标题用宋体 / Newsreader，正文用黑体，对比强烈
- **稀疏排版**：每屏信息密度低，仅突出当下操作
- **细线分隔**：1px 极浅米线，不用卡片堆叠
- **无阴影**：组件零阴影，靠分隔线和留白分层
- **暖金点缀**：仅选中态 / CTA 用暖金色，其余克制

**视觉灵感**：Kinfolk 杂志、无印良品手册、Apple Books 阅读器

**典型页面氛围**：

打开 APP，米白背景映入眼帘，顶部一行宋体大标题"如画"，下方一行小字"框住光，皆成画卷"。中间是大片留白，仅一张最近拍摄的作品预览图，下方一个暖金色细描边的圆形快门按钮。整个界面像翻开一本摄影画册。

### 6.2 联网版「画集」—— 暖意编辑式 bento 社区

**风格关键词**：温暖、连接、bento 网格、烟火气、内容驱动

**核心设计语言**：

- **Bento 网格**：不对称 CSS Grid 布局，大小卡片错落
- **1px 边框卡片**：卡片靠 1px 极浅暖线分隔，圆角 8-12px，无阴影
- **内容为王**：作品图占满卡片，文字极简（作者 + 模板名 + 数据）
- **暖橙点缀**：CTA / 选中 / 挑战赛徽章用暖橙，社区活力色
- **数据可视化**：下载量 / 收入 / 排名用 SF Mono 数字 + 极简图表
- **微动效**：列表项级联淡入，卡片按下 scale(0.98)

**视觉灵感**：Notion 模板市场、Are.na、小红书编辑流、Apple App Store Today

**典型页面氛围**：

打开 APP，米白底上方是"画集"宋体标题，下方是 bento 网格：左侧大卡片是"本周精选模板"（封面图 + 作者 + 下载量），右侧两个小卡片分别是"挑战赛 #夏日海边"和"新晋创作者"。再往下是热门作品瀑布流，每张作品下方仅显示所用模板名（暖橙小字"拍同款"）。整体像一份精致的摄影周刊。

### 7.4 间距系统（8px 栅格）

所有间距为 8 的倍数：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96

- 单机版偏大：常用 24 / 32 / 48 / 64（留白多）
- 联网版偏紧凑：常用 12 / 16 / 24 / 32（信息密）

### 7.5 图标系统

**图标风格**（双版本共用）：

- 风格：Phosphor Icons Bold 或 Radix UI Icons（细而有力）
- 描边：1.5px
- 圆角：末端圆角
- 尺寸：16 / 20 / 24 / 32px
- 颜色：跟随当前文字色，选中态用品牌色
- 不用：Lucide、Feather、Heroicons（避免通用感）

**自定义图标**（产品专属）：

- 取景框图标（四角 L 形）
- 模板图标（方框 + 叠图）
- 姿势图标（人形轮廓）
- 拍同款图标（相机 + 箭头）
- 挑战赛图标（奖杯 + 光核）

### 7.6 动效规范

**单机版动效**（极简）：

- 页面切换：150ms 淡入淡出
- 按钮按下：scale(0.98)，100ms
- 列表项进入：translateY(8px) + opacity 0→1，400ms
- 取景器叠图显隐：200ms 透明度过渡

**联网版动效**（适度丰富）：

- 列表级联：animation-delay = index × 60ms
- 卡片悬浮：背景色微变 #FFFFFF → #F9F6F0，200ms
- 点赞：暖橙红心 scale 1→1.3→1，300ms 弹性
- 挑战赛徽章：微旋转 +15° → 0°，400ms

**性能纪律**：仅动画 transform 与 opacity，不触发 layout；will-change 谨慎使用。

## 9. 设计纪律与禁忌

### 9.1 必须遵守

- 严格使用第 4 节配色色板，不引入色板外颜色
- 严格使用第 5 节字体系统，不引入 Inter / Roboto / Open Sans
- 严格使用 8px 栅格间距系统
- 所有卡片用 1px 边框 + 无阴影（或阴影 < 0.05 不透明度）
- 所有按钮圆角 4-6px，仅小徽章用 pill
- 所有分隔线 1px 极浅色
- 所有数字用等宽字体 SF Mono

### 9.2 严格禁止

- 渐变背景 / 霓虹色 / 玻璃拟态
- 重投影 / 大圆角胶囊容器
- 纯黑正文文字
- 通用图标库（Lucide / Feather / Heroicons）
- 大面积品牌色铺色块
- 拉伸变形 LOGO
- 给 LOGO 加投影 / 发光 / 渐变
- AI 套话文案（"无缝"/"提升"/"释放"/"下一代"/"颠覆"）
