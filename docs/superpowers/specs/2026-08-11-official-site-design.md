## 1. 目标

为「如画 Lumira」App 设计一个官方网站落地页（桌面端为主，适配移动端），用于品牌介绍 + 产品价值传达 + 下载引导。

- 中文名：如画
- 英文名：Lumira
- 副标语：如你所见，皆成画卷

## 2. 页面形态

**单页长滚动站（One-page scroll）**，一页 9 个区块，顶部锚点导航。

## 3. 页面结构

## 4. 视觉规范（严格遵循品牌文档）

### 4.1 配色（米白暖金墨）

| 角色 | 色值 | 用途 |
|---|---|---|
| 画布底色 | `#FAF7F2` | 全局背景 |
| 卡片表面 | `#FFFFFF` | 卡片 |
| 次级表面 | `#F2EEE6` | 分组背景 |
| 主文字 | `#1A1A1A` | 标题 / 正文 |
| 次文字 | `#5C5852` | 辅助说明 |
| 弱文字 | `#9C9690` | 占位 / 禁用 |
| 分隔线 | `#EAE5DC` | 1px 分隔 |
| 品牌主色 | `#C9A96E` | CTA / 选中 / 点缀 |
| 品牌辅色 | `#A88550` | 按下态 |

**纪律**：不用渐变背景、不用重阴影（<0.05）、暖金不大面积铺色、分隔线 1px 极浅色。

### 4.2 字体

- 中文标题：Noto Serif SC（衬线，字距 -0.02em ~ -0.03em）
- 中文正文：Noto Sans SC
- 禁用：Inter / Roboto / Open Sans
- Google Fonts 通过 `<link>` 引入（项目惯例，不用 @import）

### 4.3 组件

- 卡片：1px 边框 `#EAE5DC`，圆角 12px，无阴影
- 按钮：主按钮暖金底白字圆角 6px；次按钮 1px 暖金描边
- 徽章：pill 形，淡彩底（`#F5EDDB`/`#8C7340` 等）
- 间距：8px 栅格（4/8/12/16/24/32/48/64/96），页面边距 24-32px，区块间距 64px+

### 4.4 LOGO

复用 `assets/logos/lumira/` 现有 SVG（主标 / 文字标 / 符号标），不重新设计。

## 5. 技术方案

- 位置：项目根新建 `official-site/` 独立静态目录（不入 uni-app / Flutter 工程）
- 文件：`official-site/index.html` + `official-site/css/style.css` + `official-site/js/main.js`
- 技术：纯 HTML + CSS + 原生 JS（滚动淡入动效，仅 transform/opacity）
- 部署：可直接静态部署至 Vercel / nginx，不依赖后端
- 图片：picsum.photos（延续项目惯例，`https://picsum.photos/seed/<seed>/<w>/<h>`）
- 图标：Phosphor Icons（项目惯例，CDN 引入）
- 下载链接：真实商店链接未知，先用占位 `#`，待提供 App Store / 安卓 / 鸿蒙地址后替换
- 响应式：桌面优先，`max-width: 1200px` 内容容器，移动端单列堆叠

## 6. 动效（极简）

- 区块滚动进入：`translateY(8px) + opacity 0→1`，400ms，`fill-mode: both`
- 按钮按下：`scale(0.98)`，100ms
- 导航锚点：平滑滚动
- 仅动画 transform 与 opacity

## 7. 文案要点

- 禁用 AI 套话（"无缝"/"提升"/"释放"/"下一代"/"颠覆"）
- 标题用宋体，短句留白
- 副标语仅出现于 Hero 与页脚

## 8. 验收标准

1. 9 个区块完整，锚点导航可跳转
2. 严格使用品牌色板与字体系统，无渐变、无重阴影
3. 桌面（≥1200px）与移动端（≤480px）均布局正常
4. 滚动淡入动效生效，无白屏 / 内容不可见问题（fill-mode: both）
5. 纯静态，无构建步骤，双击 index.html 或静态服务器即可预览
