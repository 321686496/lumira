# 碎片海报 V18 · 不对称记忆墙设计

## 背景

`fragment_poster_v17_emotional.html` 的三版式仍以“对角斜裂拼板”为核心隐喻，视觉结构偏模板化，照片的收集记忆感不足。V18 不继续深化裂片隐喻，改用不对称照片墙表达“真实拍摄记录”。

## 目标

- 提供一版 `3:4` 竖版 HTML 视觉稿。
- 保留暖白、金色、衬线字体的品牌方向。
- 让真实照片成为画面主角，降低拼图模板感。
- 保持收集进度清晰，但底部信息更轻量。

## 非目标

- 不修改 Flutter 实现。
- 不新增后端数据结构或接口。
- 不替换品牌色体系。
- 不支持海报内容编辑。

## 版式结构

海报固定为 `3:4` 竖版，整体分为四层：

1. **顶部品牌层**
   - 左侧展示 `LUMIRA · 如画`，下方标注 `光影碎片集`。
   - 右侧放置轻量胶囊印章 `拼碎片`。
   - 不使用整圈外框，避免证书感。

2. **左对齐标题层**
   - 主标题使用衬线字体，例如 `光，正一片片归位`。
   - 副文案保持一句短句，强调照片记录和光影收集的过程。
   - 标题与照片墙之间保留自然呼吸空间。

3. **不对称照片墙**
   - 使用 5 个照片槽位，其中 3 个已收集、2 个待拼，对应 `3 / 5` 的静态示例。
   - 左上放置一张大图，作为当前视觉主角。
   - 右上放置一张已收集中图，中部右侧为待拼槽位。
   - 左下放置一张已收集横向长图，右下为待拼槽位。
   - 已收集照片填满槽位；未收集槽位使用米白底、金色虚线边和 `待拼` 文案。
   - 照片边缘保持轻微圆角，不使用斜裂裁切。

4. **轻量进度层**
   - 左侧展示大号数字 `3 / 5`。
   - 右侧或下方使用金色分段进度条。
   - 补充一句极简邀请文案，例如 `还差 2 帧 · 一起凑齐这束光`。
   - 不再重复长段品牌语，保留页面底部细小品牌标识即可。

## 视觉约束

- 底色：暖白到米白之间的柔和渐变。
- 主金色：`#C9A96E`；深金色：`#A9884B`；墨色：`#2A241C`。
- 照片区可使用浅金描边，但避免厚重阴影和复杂装饰。
- 中文标题使用 Noto Serif SC / Songti SC 类衬线字体。
- 正文和辅助信息保持小字号、低对比、不干扰照片。

## 验收标准

- 海报为 `3:4` 竖版。
- 5 个槽位呈现清晰的不对称关系。
- 已收集与未收集状态在视觉上可立即区分。
- 底部进度信息一眼可读。
- 整体观感更接近私人照片记忆墙，而非裂片证书或规则网格模板。
