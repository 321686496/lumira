## 0. 文档说明

本文档定义独立产品「如画 Lumira」的完整需求：

**如画 Lumira** —— 完全离线、纯净无网络依赖、无 AI 的随身摄影工具。通过本地内置的拍摄模板（构图叠图 + 姿势参考 + 相机参数 + 后期调优包）和代码级图像算法，帮助普通用户在不联网的情况下也能拍出专业级好照片。

产品英文名 Lumira（造词：Lumi=光，-ra 后缀），中文名「如画」取"如你所见，皆成画卷"之意。

## 1. 产品概述

### 1.1 一句话定位

让普通人拍出专业级好照片的随身摄影助理——通过"拍摄模板"将专业摄影师的构图、姿势、参数、后期经验固化为可复用方案，小白套用即拍，进阶可二次创作。

### 1.2 解决的痛点

普通人拍照常遇到的痛点：

- 不会构图，不知道主体放哪、画面如何安排
- 不会摆姿势，拍出来僵硬、不自然
- 不懂相机参数，曝光/白平衡/对焦把握不准
- 不会后期，调色/磨皮/裁剪无从下手
- 想学摄影但身边没有专业指导

### 1.3 解决方案

把专业摄影师的经验结构化为「拍摄模板」，一个模板包含：构图叠图、姿势参考轮廓、相机参数预设、场景拍摄指南、后期调优参数包。用户套用模板即获得取景框内的可视引导 + 一键应用的参数，从"拍"到"修"形成完整闭环。

### 1.4 核心差异化定位

| 维度 | 如画 Lumira |
|---|---|
| 网络依赖 | 完全离线（零网络权限，可审计） |
| AI 能力 | 无（纯代码算法 + 预设参数 + LUT 查找表） |
| 模板来源 | 内置精选模板 + 本地创建 + 文件导入 |
| 模板流通 | 导出 `.pptpl` 文件 → 系统分享 → 其他用户导入 |
| 账户体系 | 无（本地设备 ID 用于作者标识） |
| 商业模式 | 免费 + 付费模板包（模板付费，平台分成） |
| 工程形态 | 独立 uni-app 工程 |

### 1.5 核心价值主张

把"专业摄影师脑子里的经验"变成"小白取景框里看得见的引导线 + 一键应用的参数"。

### 1.6 品牌身份

- 中文名：如画
- 英文名：Lumira
- 副标语：如你所见，皆成画卷
- LOGO：单取景框 + 斜射光 + 焦点光点（暖金 + 米白 + 墨色）
- 设计风格：东方编辑式留白，衬线主导，极简精致

## 2. 用户角色与典型场景

### 2.1 用户角色

| 角色 | 说明 | 核心诉求 |
|---|---|---|
| 摄影小白 | 完全不懂参数，想拍出好看照片 | 套模板即拍，得到好照片 |
| 进阶爱好者 | 有一定基础，想提升构图/姿势 | 学习专业模板的构思与参数 |
| 创作者（PGC） | 专业摄影师在本地创作模板 | 创作模板导出分享 |

### 2.2 典型场景

1. **旅行打卡**：小白到了网红机位，打开「如画」选"旅行人像"模板 → 取景框叠加构图线 + 姿势轮廓 → 按提示设置参数 → 拍摄 → 一键套用后期参数包 → 成片。
2. **探店自拍**：选"咖啡馆半身"模板 → 姿势叠图引导 → 拍后调色参数包自动应用 → 导出分享朋友圈。
3. **创作者分享**：专业摄影师A使用模板编辑器创作了一个"室内静物"模板 → 导出 `.pptpl` 文件发给朋友B → B导入到自己的「如画」中使用。
4. **学习摄影**：进阶爱好者下载了一批专业模板 → 逐个打开取景器学习构图引导线的位置和参数设置 → 理解专业摄影师的拍摄思路。

## 3. 模板体系

### 3.1 模板定义

「拍摄模板」是一份可复用的"拍摄方案包"，是产品的最小价值单元。

### 3.2 模板文件格式（`.pptpl` JSON 格式）


### 3.3 模板流通路径

- 内置精选模板（随安装包携带）
- 本地创建/编辑（模板编辑器）
- 导出 `.pptpl` 文件 → 系统分享（微信/文件管理器/AirDrop）
- 从文件/相册/分享接收导入
- **互通性**：导出的 `.pptpl` 文件可被联网版「画集 Lumira Studio」导入发布；从联网版导出的模板也可被「如画」导入使用

### 3.4 模板兼容性

模板含 `version` 字段，引擎做向后兼容处理：加载时校验版本，旧版本模板自动迁移或提示升级。

### 3.5 模板创建工具

内置「模板编辑器」：

- 上传姿势参考图（透明 PNG）
- 绘制构图叠图（路径/九宫格/三分法/自定义形状）
- 调试相机参数
- 调试后期参数（实时预览效果）
- 预览 → 保存为 `.pptpl`

编辑结果仅存本地，可导出分享。

## 4. 功能设计

### 4.1 功能架构

```
如画 Lumira
├── 拍摄模块（核心）
│   ├── 自定义相机取景器（叠加构图线/姿势轮廓/参数提示）
│   ├── 模板套用拍摄（加载模板→实时叠图→参数引导→拍摄）
│   ├── 自由拍摄（无模板，仅基础相机）
│   └── 拍摄参数面板（手动调节曝光/白平衡/对焦等）
├── 后期模块（本地代码算法）
│   ├── 模板后期一键应用（套用 postProcess 参数包）
│   ├── 手动调整（裁剪/调色/磨皮/锐化/滤镜）
│   ├── EXIF 读写与参数还原
│   └── 导出（分辨率/水印/格式）
├── 模板模块
│   ├── 模板库（内置精选 + 已导入）
│   ├── 模板编辑器（创建/编辑/调试）
│   ├── 模板导出（.pptpl 文件，系统分享）
│   └── 模板导入（从文件/相册/分享接收）
├── 我的相册（本地照片管理，按模板/时间/场景分类）
└── 设置（无账户体系，纯本地偏好）
```

### 4.2 核心拍摄流程（关键路径）

```
选模板 → 进取景器 → [实时叠图：构图线+姿势轮廓+主体框]
       → 顶部提示：光线方向/距离/镜头
       → 参数引导：显示模板建议参数，用户可"一键应用"或手动调
       → 对齐检测（代码算法：主体是否落入框内/水平线是否水平）
       → 拍摄 → 进入后期 → 一键套用 postProcess → 微调 → 保存/分享
```

### 4.3 实时叠图实现

基于 uni-app 的 `camera` 组件 + 自定义叠加层（nvue/原生插件）渲染半透明图层。姿势轮廓与构图线作为半透明图层覆盖在取景器上，支持透明度调节与显示/隐藏切换。

### 4.4 对齐检测（纯代码算法，非 AI）

- **水平线检测**：基于陀螺仪/加速度计传感器数据判断手机水平状态。
- **主体框对齐**：基于边缘检测/肤色检测的轻量 OpenCV 算法（本地运行），提示"主体偏左/偏右/偏上/偏下"。
- **范围**：仅做简单色彩/边缘区域占比判断，不做人脸识别（避免引入 AI 模型）。

### 4.5 本地后期算法（代码调优，无 AI）

| 功能 | 算法实现 |
|---|---|
| 调色（亮度/对比度/饱和度/色温/色调） | 像素级 LUT/矩阵变换，基于查找表 |
| 裁剪/旋转 | Canvas 像素重采样 |
| 磨皮 | 保边滤波（双边滤波）+ 肤色掩膜 |
| 锐化 | Unsharp Masking |
| 暗角/颗粒 | 径向渐变叠加 / 噪点生成 |
| 滤镜 | 颜色查找表（LUT `.cube` 文件） |

> **明确排除**：单机版**不包含**瘦脸、大眼、五官精修等人脸相关功能（这些依赖人脸关键点检测）。

### 4.6 模板编辑器（创作者工具）

- 入口：我的 → 模板编辑器
- 能力：上传姿势参考图（透明 PNG）→ 绘制构图叠图（路径/九宫格/三分法）→ 调试相机参数 → 调试后期参数 → 预览效果 → 保存为 `.pptpl`
- 编辑结果仅存本地，可导出分享

## 5. 技术架构

### 5.1 技术选型

| 层 | 选择 |
|---|---|
| 前端框架 | uni-app (Vue3 + TS) |
| 相机/图像 | uni-app camera 组件 + 原生插件（原生相机/OpenGL 渲染） |
| 本地算法 | OpenCV.js / 原生 C++ 插件（LUT/保边滤波/锐化） |
| 数据库 | SQLite（本地模板库/照片索引） |
| 存储 | 本地文件系统 |

### 5.2 架构设计

```
[UI 层 Vue3]
   ↓
[业务逻辑层] 拍摄管理 / 后期引擎 / 模板引擎 / 相册管理
   ↓
[核心服务层]
   ├── 相机服务（原生插件：取景 + 叠图渲染 + 参数控制）
   ├── 图像处理引擎（原生 C++/OpenCV：LUT/滤波/锐化/裁剪）
   ├── 模板引擎（模板加载/解析/应用/序列化 .pptpl）
   └── 本地存储（SQLite + 文件系统）
   ↓
[平台层] iOS/Android 原生能力（传感器/相册/分享）
```

**关键点**：

- 相机叠图需原生插件实现高性能渲染（uni-app 原生组件 cover-view 性能有限，复杂叠图需 nvue/原生插件）。
- 图像处理走原生 C++ 保证性能。
- 整个工程不含任何网络请求代码与权限声明。

### 5.3 模板文件互通规范

`.pptpl` 为统一的 JSON 格式文件。模板引擎使用独立的 TS 类型定义与序列化/反序列化逻辑，确保与联网版「画集」互通：

- 导出的 `.pptpl` 可被联网版导入并发布
- 联网版下载的 `.pptpl` 可导入到「如画」使用
- 模板含 `version` 字段，引擎做向后兼容处理

## 附录 A：术语表

- **模板（Template / `.pptpl`）**：一份可复用的拍摄方案包，包含构图叠图、姿势参考、相机参数、场景指南、后期参数。
- **叠图（Overlay）**：取景器上覆盖的半透明引导图层（构图线/姿势轮廓/主体框）。
- **LUT（Look-Up Table）**：颜色查找表，用于实现滤镜与调色。
- **PGC**：专业生产内容（Professional Generated Content）。
- **EXIF**：图像文件元数据，记录相机参数等信息。
