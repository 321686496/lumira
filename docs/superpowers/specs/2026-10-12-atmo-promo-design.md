# 如画推广短片「脸不好看怎么出片」设计（AtmoE01）

日期：2026-10-12 ｜ 状态：已与用户对齐骨架，本文档为定稿设计

## 1. 背景与目标

- 平台：抖音 + 小红书，竖屏 9:16（1080×1920），35s @ 30fps = 1050 帧
- 选题：脸不好看怎么出片？→ 氛围感拍照风格
- 核心叙事：不卖"修脸"，卖"换拍法"——脸不进画面、氛围当主角
- 防限流红线：正片零导流元素（无二维码、无应用商店标、无「下载」字样、无点击手势、无其他平台名）；转化挂发布侧（抖音蓝 V 应用锚点 / 小红书报备组件 + 置顶评论）
- 与 app 真实功能对齐：模板（构图/姿势/场景引导 + ambience 氛围分类）→ 跟拍 → 本地后处理出片；不出现"AI 一键换脸"等不存在的功能

## 2. 工程位置与复用

- 工程：`lumira-promo-video/`（Remotion 4.0.534 + React 19），**新增 composition，不新建工程**
- 新增文件：`src/atmo/AtmoE01.tsx`（单文件 + 局部组件，仿 `src/replay37/E01.tsx` 模式）、`src/atmo/AtmoCover.tsx`（小红书封面）
- 修改：`src/Root.tsx` 注册两个 composition
- 复用：`v2/theme`（V/FONT2/goldInk）、`v2/ink`（Paper/InkPath/Stamp/StickyCap/DrawOnImage）、`v2/props`、`replay37` 的 VPolaroid/SparkleBurst 模式（拷贝为局部组件）、`public/sfx/*`
- 素材：AI 生成，放 `public/atmo/`

## 3. 视觉体系

- 沿用工程既有手绘纸感 MG 体系：纸底 + 纤维噪点 + 暗角（Paper）、墨线生长（InkPath）、盖章（Stamp）、拍立得相框、手写体字幕（StickyCap）
- 冷暖叙事承载「转折」：前段灰墨废片（gray/ink 单色、惨白感）→ 8s 处金光一闪（gold radial + 星尘迸发）→ 后段金调成片
- 运镜铁律（无静态死图超 2s）：急推放大 + 抖动、卡片甩入（spring + rotate ±1.6°）、翻转进出、呼吸光点、结尾成片墙

## 4. 分镜（30fps，帧段）

| 帧段 | 拍 | 画面 | 字幕 Cap | SFX |
|---|---|---|---|---|
| 0–90 | P0 钩子 | AI 怼脸翻车自拍拍立得急推放大 + 抖动，红章「脸不好看」 | 「脸不好看，怎么出片？」 | shutter |
| 90–240 | P1 共鸣 | 三张废片卡依次甩入：怼太近 / 光死白 / 背景乱（手绘 props） | 「每次拍照都翻车？」 | pop ×3 |
| 240–360 | P2 转折 | 金光一闪、星尘迸发，竖排大字「别拍脸，拍氛围」（金色渐变字） | — | riser + ding |
| 360–660 | P3 三招 | 藏（360–460）侧脸背影剪影 / 光（460–560）逆光窗光光斑 / 远（560–660）小人物大环境；每招：AI 示例拍立得 + 手绘标注 + 关键词印章 | 「侧身藏进光影里」「让光替你说话」「退远，环境讲故事」 | pop / shutter |
| 660–900 | P4 产品 | 手机样机（仿 TemplatePhone）：模板库列表 → 模板详情（三分线构图 + 姿势剪影 + 参数 pill）→ 成片；before/after 擦除对比 | 「不用学，跟着模板拍就行」 | pop |
| 900–1050 | P5 CTA | 成片墙（4 张 AI 氛围片拍立得散落）+ 品牌章「如画」+ slogan「跟着拍，就有氛围感」；零导流元素 | 「跟着拍，就有氛围感」 | whoosh |

slogan「跟着拍，就有氛围感」为占位，用户可替换。

## 6. 平台输出

- 主片：`AtmoE01` 1080×1920 × 1050f，`npx remotion render AtmoE01 out/atmo-e01.mp4`（抖音/小红书共用）
- 小红书封面：`AtmoCover` 3:4 1080×1440 × 30f（三招三联拍立得 + 大字「氛围感三招」），`npx remotion render AtmoCover out/atmo-cover.mp4` 后抽帧作封面

## 7. 验收标准

1. `npm run lint`（eslint + tsc）通过；`npx remotion studio` 预览无报错
2. 全片无静态死图超 2s；每拍有运镜/动效
3. 0–3s 钩子含大字与急推；P2 转折色调突变明确
4. 结尾帧审查：无任何导流元素
5. 渲染成功且成片可播放；P4 演示与 app 真实链路一致
