# 如画 Lumira · 商店上架文案 ASO 优化 设计说明

> 版本 v1.0 | 2026-09-27
> 目标：提升 **华为应用市场（HarmonyOS / AppGallery）** 与 **App Store（中国大陆区）** 的搜索曝光与转化
> 落地文件：`上架运营/app-store-upload-spec.md`（v1.1.0 → v1.2.0）

---

## 1. 目标与约束

**目标**：应用商店搜索优化（ASO），非答案引擎优化（AEO）。

**硬约束（来自平台官方规则）**：

| 平台 | 字段 | 限制 | 是否参与搜索索引 |
|---|---|---|---|
| iOS App Store | 名称 | ≤30 字符 | 是（权重最高） |
| iOS App Store | 副标题 | ≤30 字符 | 是（高权重） |
| iOS App Store | 关键词字段 | ≤100 字符，英文逗号分隔、**逗号后无空格** | 是（强权重，不可见） |
| iOS App Store | 描述 | ≤4000 字符 | **否**（仅影响转化） |
| iOS App Store | 宣传文本 | ≤170 字符 | **否**（可随时改） |
| 华为 AppGallery | 应用名称 | ≤15 汉字，**须与软著名称/简称一致** | 是 |
| 华为 AppGallery | 一句话简介 | ≤17 汉字 | 是 |
| 华为 AppGallery | 应用介绍 | ≤8000 字符 | 是（长尾） |
| 华为 AppGallery | 新版本特性 | ≤500 字符（中国大陆） | 辅助更新页曝光 |

**产品事实约束**：产品**无「修图 / 滤镜」能力**，此类词不得出现在任何文案（合规红线，同时避免差评与审核风险）。

## 2. 目标词表（分层：20% 核心 + 80% 长尾）

| 级别 | 词 | 承载位置 |
|---|---|---|
| 核心（差异化） | 拍照姿势、姿势模板、拍照模板、剪影、摆姿、构图 | iOS 名称 + 副标题；华为一句话简介 |
| 场景长尾 | 探店、人像、咖啡店、旅行、街拍、夜景、美食、自拍、情侣、合照、闺蜜 | iOS 关键词字段；华为应用介绍 |
| 泛流量 | 拍照、摄影、相机 | 应用介绍自然出现 |
| 情绪人群 | 氛围感、教程、打卡、日记、大片、写真 | iOS 关键词字段 |
| 品牌 | 如画、Lumira | iOS 名称；华为名称（软著锁定） |

**禁用词**：修图、滤镜、一键 P 图。

## 3. 决策要点

1. **名称与副标题去重**：iOS 名称锁「品牌中文词 + 核心词」，副标题只放名称未覆盖的词（剪影/引导/摆姿/人像/探店/构图/出片），避免重复消耗曝光位。
2. **关键词字段只放长尾**：剔除已在名称/副标题/主分类出现的词，全部用于场景长尾，98/100 字符。
3. **华为名称不可加词**：华为要求名称与软著简称一致，锁定为「如画 Lumira」；因此华为端搜索覆盖全部压到 17 字一句话简介 + 应用介绍。
4. **华为一句话简介必须压缩**：旧文案为 80+ 字长句，超华为 17 字硬上限，无法提交；新版 15 字。
5. **描述/宣传文本不作为搜索手段**：iOS 描述不参与索引，维持转化导向即可，不在其中堆词。

## 4. 验收标准

- iOS 名称 ≤30、副标题 ≤30、关键词 ≤100 且无「名称/副标题/分类」重复词、无逗号后空格
- 华为名称与软著简称一致、一句话简介 ≤17 汉字
- 全文无「修图 / 滤镜」等不实能力表述
- 用脚本对四个索引字段做字符数断言

## 5. 后续优化（登记到 `docs/future-optimizations.md`）

- 接入华为「关键词分析工具」/ App Store Connect 后台数据，用真实搜索量与竞争度迭代词表
- 评论运营（带关键词好评）与版本更新融入关键词，形成 ASO 闭环
- 观察 iOS `app tags`（LLM 从元数据生成）表现，反向校准元数据
