# 双节专项推流（中秋+国庆 Campaign）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 借中秋（9/25-9/27）+国庆（10/1-10/7）双节出游拍照热点，后台上新 2+4 个节日主题模板，并产出小红书 3 篇 + 抖音 2 条节日内容按排期发布。

**Architecture:** 模板上新走后台 admin「一键生成模板」wizard（AI 生成姿势图/剪影/封面 → 表单确认 → 上架，即时生效无需发版，App 进"发现"页自动拉取）；内容产出为可直接发布的完整文案/脚本（小红书 3 篇 + 抖音 2 条）。发布后按执行手册指标复盘。

**Tech Stack:** 后台 admin（Next.js，`ai-create` wizard + `TemplateForm`）；后端（NestJS，`POST /admin/templates`、`POST /admin/categories`）；App（Flutter，`GET /api/v1/templates/list` 自动同步）；发布平台（小红书 / 抖音，个人号）。

## Global Constraints

- 发布口径：个人号发布、无官方蓝 V；CTA 统一"应用商店搜索「如画 Lumira」"；**商店链接后补**，当前不写链接。
- 合规红线（每条内容遵守）：①只讲真实功能（姿势剪影/60+模板/分享海报/每日灵感/打卡挑战/邀请有礼/多UI风格/离线可用），不出现不存在的"修图/滤镜/一键逆天改图"；②不写"免费"误导，积分口径=邀请各+30→解锁付费模板；③示例图标注"效果示意"；④避免绝对化用语（最/第一/顶级）；⑤不虚构人设、不冒充官方。
- 模板名称必须具体（如「古风赏月·侧身提灯」），描述聚焦情感价值。
- 模板上新走后台 wizard，生成结果即线上模板（isActive=1）；**绝不发布未验证的模板**——上架前必须 App 真机预览剪影叠加正常。
- 后台操作基于真实后台站点（Vercel 部署的 admin / 本地 dev），操作时使用实际已登录会话。
- 涉及后端/后台代码改动时按 AGENTS.md：commit 后 push 双远程（gitee origin + github），但本计划默认**零代码改动**（纯后台操作 + 内容创作），如遇必须改代码的情况单独确认。
