## 一、这一波解决什么问题（诊断）

上一波「互动破冰波」解决的是**「没人开口」**；这一波解决的是**「内容没有可以带走的实用价值」**。

前几波数据回看：

| 平台 | 现状 | 判读 |
|---|---|---|
| 小红书 | 4 篇笔记，曝光 249–596，封面点击率 7.4%–9.2%，互动 0–1 | 封面能拉住人，但**看完就走**——没有"值得存下来"的东西，所以没有收藏、没有关注 |
| 知乎 | 阅读 37 | 缺一个"搜得到、用得上"的干货落点 |
| 公众号 | 总用户 3 | 靠推送不现实，只能靠单篇的**可转发性** |

**新增变量：两套上线模板的真实样片已经拿到**（`日系可爱少女火锅探店打卡` 9 张 + `蓝调海滨少女人像` 9 张，含每张对应的姿势名与摆法描述）。这意味着我们终于可以把「9 个姿势」做成一张**读者可以直接照着摆的对照表**，而不是只讲道理。

## 三、主抓手：一张「9 姿势图鉴」

### 为什么是「图鉴」而不是「教程」

- **图鉴 = 可保存**。收藏是小红书权重很高的行为；"9 个姿势"天然是一张表，读者第一反应是存下来。
- **图鉴 = 不用动脑**。教程要求读者理解，"图鉴"只要求读者照着摆。
- **图鉴 = 能复用**。同一个模板里的 9 个姿势是一条完整路线，出门前看一眼就能拍完一组，不会拍到第 3 张就没招了。

### 为什么可信

配图与文案直接用**模板内的真实样片**（App 里 `模板详情页` 的那 9 张），不是生图、不是摆拍概念图；每张都对应一个真实存在的姿势名。截图与样片统一标注「效果示意」。

### 视觉锤（延续）

**取景框 + 半透明剪影轮廓**：App 拍摄页在取景框上叠一层人形轮廓，手放哪、脚怎么站、人在画面里占多大全部框出来，照着对齐即可。这是「图鉴」的可执行版本，也是和同类内容拉开差距的点。

## 七、发布后 1 小时（本波真正的落点）

1. **作者置顶一条提问评论**：正文只留一个引导，真正的提问用第一条评论发出并置顶（话术见各篇文件）。
2. **去 5–10 个同赛道热门笔记下留真实评论**：讲自己的一次翻车经历，或补一条具体建议；不硬广、不复制粘贴。
3. **24 小时内逐条回复**：回复里再抛一个小问题，把单次互动变成来回对话。
4. **不刷量**：不使用机器赞/机器评。

## 八、合规红线（违反即不合格）

| 红线 | 要求 |
|---|---|
| 商店链接 | **不写**任何应用商店链接 |
| "免费" | 全文**不出现**"免费"二字及相关承诺 |
| iOS 状态 | 只能写「iOS 即将上架 / 审核中」，**禁写**「iOS 已上架」 |
| 统一 CTA | 「应用商店搜『如画 Lumira』，鸿蒙已上架，iOS 即将上架，可以先收藏」 |
| 绝对化用语 | 不用「最 / 第一 / 唯一 / 100%」等（"最想删""最喜欢"等指向读者个人偏好的表述也尽量改写） |
| 效果示意 | 样片、截图、示意图一律标注「效果示意」 |
| 不承诺效果 | 只讲「有参照、照着摆」，不承诺"必出片""零废片" |
| 不杜撰数据 | 只引用真实数据；"9 个姿势""60+ 模板"等须与 App / 商店口径一致 |
| 身份口径 | 个人号口径；需要时如实自曝"这是我参与开发的 App" |

## 九、复盘口径

- 记录每篇：曝光、封面点击率、收藏、评论数、评论**质量**（是否有人真的在选姿势 / 点单 / 晒图）。
- **对比两篇图鉴**：火锅 vs 海边，哪一种场景的收藏率更高 → 决定下一波主打场景。
- 若某篇 24 小时收藏 < 10，优先换首图（九宫格 → 单张大图）重发一版，而不是放弃选题。
- ③ 的点单结果必须在下一期真实兑现，否则会掉信任。
