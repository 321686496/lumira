## 一、品牌定位与核心记忆点

**一句话定位**：「如画」把专业摄影师的经验变成取景框里看得见的姿势剪影，照着摆，就能出大片。

**本次传播只卖一个核心记忆点**：

> 「不会摆姿势？照着取景框里的剪影摆，秒出大片。」

- **视觉锤**：取景器上叠着人形剪影的界面特写（所有封面/头图统一用这个画面，反复出现形成识别度）。
- **口语锤**：「照着剪影摆」——五个字，说一遍就懂，能被用户复述。
- 其余功能（模板库、每日灵感、拍摄日记、打卡挑战、分享海报、邀请有礼、多 UI 风格、离线可用）全部作为第二卖点，不抢戏。

**四大差异化能力**（下文所有内容只讲这些真实功能，绝不杜撰）：

| 能力 | 一句话 |
|---|---|
| 姿势剪影引导 | 不会摆姿势/不懂构图？剪影叠在取景器上，跟着摆就对齐 |
| 60+ 精品模板 | 人像/探店/美食/街拍/夜景/静物/微距，线上每周上新 |
| 每日灵感推荐 | 根据天气、时间、偏好推荐"今天拍什么" |
| 拍摄日记 + 打卡挑战 | 按时间轴整理作品，月度回顾，连续打卡解锁专属模板 |
| 一键分享海报 | 拍完直接生成专属海报，扫码还能拍同款 |
| 邀请有礼 | 邀请好友，双方各 +30 积分，积分解锁付费模板 |
| 界面审美 | 四种 UI 风格（新拟态/扁平/玻璃/女性美学）+ 8+ 主题色 |
| 轻负担 | 离线可用，不强制登录注册 |

### 6.1 小红书（8 篇完整）

**运营细则**：像分享，不像广告——正文"我"的戏份要多；首图统一"取景器+剪影"视觉锤；发布后 1 小时内小号评论区互动；封面 CTR < 8% 换封面重发；笔记①自然数据（点击率 > 10%、收藏 > 30）达标后投 50-100 元薯条测放量。

**评论区话术储备**：
- "安卓能用吗？" → "现在上架了 iOS 和华为（鸿蒙）应用市场，其他机型在规划中，可以关注一下～"

##### 📖 长文 2｜C 实用干货系

**为题**：手机拍人像，怎么避免"游客照"既视感？

**正文（结构要点）**：
```
一、游客照 VS 氛围照，差在哪
差的不是器材，是三条：角度、构图、人物姿态。普通拍法习惯"正面+居中+全身直立"，这是最容易显"到此一游"的组合。

二、三条立刻可用的改法
1. 角度：正面改侧 30°，身体线条和景深更立体
2. 构图：人物从正中往左/右三分之一放（三分法）
3. 姿态：拒绝对称站，手有去处、重心单腿

三、当你要拍"特定风格"时怎么办
探店有探店的构图、夜景有夜景的用光、街拍有街拍的机位。不同场景要求不同，这时候"每套动作都现记"成本很高。

四、把"每套动作"变成"可选的模板"
这也是为什么一些 App 会把"特定场景怎么摆、人放哪"做成预设模板。比如「如画 Lumira」的 60+ 款模板（街拍/夜景/探店/美食等），选好场景，剪影直接给你框好位置。与其记住抽象理论，不如让模板告诉你"这个场景怎么拍"。

五、适用人群
- 旅行/探店爱好者，想拍出不同感觉
- 拍照新手，想快速上手
- 想养成记录习惯的人（配套拍摄日记、月度回顾、每日灵感推荐）

六、结语
避免游客照的本质：不要"随手一拍"，而是让画面里有"意图"。具体方式，拍照 App（HarmonyOS/App Store 搜「如画 Lumira」）是一个低门槛入口。
```
