# 国庆模板上新 · 后台操作指引

> 用途：9/28 前在后台完成「旅行」分类新建 + 4 个国庆旅行模板上新。全程手动操作，按此指引走即可。
> 目标：9/28 前模板上架并验证 → 9/28-9/30 内容备齐（文案已就绪）→ 10/1-10/4 按排期发布。

---

## 一、Task 5：新建「旅行」L1 分类

1. 打开后台 → **分类管理**
2. 新建分类：
   - 名称：**旅行**
   - key：**travel**
   - 排序/图标：按现有分类风格补齐 icon（如有）
3. 验证：后台分类列表可见「旅行」；App 模板页分类筛选出现「旅行」（进入页面自动拉取）

---

## 二、Task 6：上新 4 个旅行模板（后台「AI 一键生成」）

> 每个模板流程一致：Step1 输入（纯文字，粘贴下方描述）→ Step2 修正表单字段 → Step3 封面 → Step4 剪影 → Step5「上架」。

### 模板 1「地标打卡·张开双臂」

Step1 描述：

```
白天城市地标前的旅行人像。模特正面站在地标建筑前，张开双臂拥抱天空，身体舒展，略微仰头，笑容自然，逆光剪影轮廓清晰。构图人物居画面三分之一偏右。要求身体比例自然、无明显畸变。
```

| 字段 | 值 |
|---|---|
| name | **地标打卡·张开双臂** |
| category（L1） | **travel（旅行）** |
| 短描述 | `到一座新城市的第一件事，就是张开双臂和地标合个影。` |
| price | 0 |


| 字段 | 值 |
|---|---|
| name | **车站启程·背包回眸** |
| category（L1） | **travel（旅行）** |
| 短描述 | `出发那天的回眸，藏着对远方全部的期待。` |
| price | 0 |

```
双人旅行合影人像。两人并肩站立，各自伸出一只手在胸前比心，身体微侧向对方，笑容自然，背景为街道或自然风景，阳光柔和。要求双人剪影轮廓清晰、间距自然、无明显畸变。
```

### 模板 4「海边日落·侧坐眺望」

Step1 描述：

```
海边黄昏旅行人像。模特侧坐在礁石/沙滩上，双腿自然弯曲，侧望远方海平线，日落暖光，海浪余晖，剪影轮廓柔和清晰。要求坐姿比例自然、无明显畸变。
```

### 上架后确认
模板管理列表可见 4 个新模板，均上架（isActive=1），分类=旅行，名称/封面无误。

## 三、Task 7：真机验证

1. App 模板/发现页自动同步，确认「旅行」分类下 4 个模板出现
2. 逐个进入拍摄页检查剪影：轮廓清晰、比例正常、位置合理（「结伴出游·并肩比心」检查双人剪影间距）
3. 检查封面、详情、分类归属
4. 不达标处理：回后台改「未上架」，并从国庆内容中剔除该模板，内容改用已达标模板
