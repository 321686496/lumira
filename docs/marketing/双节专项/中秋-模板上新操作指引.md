# 中秋模板上新 · 后台操作指引

> 用途：今晚（9/24）在后台「AI 一键生成」新建 2 个中秋模板并上架。全程手动操作，按此指引走即可。总耗时约 30-40 分钟。
> 时间目标：18:00-20:00 完成上新 → 20:00-21:00 真机验证 → 21:00 发小红书。

---

## 一、进入后台 AI 生成入口

1. 打开后台 admin 站点（你平时用的地址）并登录
2. 进入 **模板管理 → AI 一键生成**（`dashboard/templates/ai-create`，5 步向导）

---

## 二、模板 1「古风赏月·侧身提灯」

### Step 1 输入（不使用示例图，纯文字）

- **文字描述/创作要求**（原样粘贴）：

```
中秋夜景古风人像。模特侧身回眸望向天上的月亮，右手手提一盏灯笼，左臂自然垂落，身体约 3/4 侧向镜头。庭院/露台背景，青石板或木质回廊，暖黄灯笼光与冷月色对比，朦胧雾气。氛围：静谧、思念、团圆。要求剪影轮廓清晰、身体比例自然、无明显畸变。
```

- **姿势个数**：选 1-2

### Step 2 风格识别后修正表单字段

| 字段 | 填写值 |
|---|---|
| name（必填） | **古风赏月·侧身提灯** |
| category（L1，必填） | **portrait（人像）** |
| classificationMajorStyle（L2） | retro_nostalgia（复古怀旧） |
| classificationSubStyle（L3） | chinese_classical（中式古典） |
| classificationMethod（L4） | 留空（`__none__`） |
| price | 保持默认 0 |
| 短描述 | `中秋月圆时，一袭长裙提灯回望，把思念拍成古画。` |

> 检查回填的 composition / pose / camera / sceneGuide / postProcess 五段是否合理，明显错误手工修正。

### Step 3 封面决策
用生成的姿势图/效果图作封面。

### Step 4 剪影决策
确认线稿剪影与姿势一致（侧身、提灯的手、回眸方向）。

### Step 5 提交
点 **「上架」**（isActive=1）。

---

## 三、模板 2「中秋拜月·双手合十」

### Step 1 输入

- **文字描述/创作要求**（原样粘贴）：

```
中秋夜景古风人像。模特正面站立，双手在胸前合十，微微仰头望向月亮，闭目许愿姿态，裙摆自然下垂。露台/庭院背景，远处一轮圆月，烛光与月光交织，柔和光晕。氛围：虔诚、静谧、祈福。要求剪影轮廓清晰、站姿挺拔、无明显畸变。
```

- **姿势个数**：选 1-2

### Step 2 修正表单字段

| 字段 | 填写值 |
|---|---|
| name（必填） | **中秋拜月·双手合十** |
| category（L1，必填） | **portrait（人像）** |
| classificationMajorStyle（L2） | retro_nostalgia（复古怀旧） |
| classificationSubStyle（L3） | chinese_classical（中式古典） |
| classificationMethod（L4） | 留空（`__none__`） |
| price | 保持默认 0 |
| 短描述 | `中秋对月合十许愿，把这一刻的虔诚留在画面里。` |

### Step 3-5
封面决策 → 剪影决策（确认合十手部、仰头姿态）→ **「上架」**。

---

## 四、上架后确认

模板管理列表应能看到 2 个新模板，状态=上架，名称/分类/封面无误。

## 五、真机验证（20:00-21:00）

1. 打开 App → **模板/发现页**（进入页面会自动拉取新模板，无需发版/手动刷新）
2. 确认 2 个新模板出现在列表（或"人像→中式古典"分类下）
3. 选中「古风赏月·侧身提灯」→ 进入拍摄页 → 检查剪影叠加：轮廓清晰、比例正常、位置合理
4. 切换「中秋拜月·双手合十」同样检查
5. 检查模板卡片封面、详情页大图、分类归属

**验证结论判断**：
- 达标 → 直接用于今晚 21:00 的小红书笔记（首图用真机取景截图 + 月亮背景）
- 不达标 → 回后台将该模板改为「未上架」，今晚笔记正文改用通用中秋氛围演示（不点名具体模板），国庆再补做
