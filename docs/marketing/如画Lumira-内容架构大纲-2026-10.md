# 如画 Lumira · 内容架构大纲（总纲 + 功能单篇系列）

> 策略：一篇总纲（承载完整功能清单，长文平台）+ 重点功能各一篇单篇（情绪价值吸睛 + 干嘛用/怎么用，适配短平快）。
> 平台分工：总纲 → 公众号/知乎；单篇 → 小红书/抖音为主，公众号/知乎转长文版。

## 一、总纲篇（发布总文）：一次性讲全这个 App

**定位**：把"如画是干嘛的 + 解决什么 + 全部功能纵览"一次讲完，作为系列的首篇（即此前《开发者官宣·功能详解主稿》，本文为它拆解/扩展）。
**吸睛标题方向**：
- 一个人用 AI 做了 3 个月的拍照 App，今天上线了
- 拍照 300 张只有 1 张能发？我写了个 App 全包
**正文结构**：
1. 痛点三连（不会摆姿/不会构图/后期翻车）→ 共鸣
2. 一句话定位：套模板、照着拍、所见即所得
3. 核心 8 大功能·速览表（名称 + 一句话作用）
4. 双端上线 + 模板持续更新
**平台**:公众号/知乎（长文全量）；小红书/抖音拆成片段预告引流到单篇
**配图**：12 张 `_i2i_full` 截图选 2-3 张 + 分享海报

## 二、功能单篇系列（每篇 = 情绪价值吸睛 + 它是干嘛的 + 怎么用）

> 每篇统一骨架：**开头情绪钩子 → 痛点场景 → 功能是什么 → 3 步怎么用 → 结尾情绪价值**。短文平台压缩"怎么用"为 3 条；长文平台展开。

### 单篇① 模板套用 · 照着拍就出片（核心功能）
- **牌子**：P0·主打
- **吸睛标题**：不会摆姿势？这条剪影直接框给你
- **痛点**：对象/朋友站得笔直、找不到角度、拍了三百张没一张
- **干嘛**：搜关键词找模板 → 一键套用 → 剪影框好构图+姿势
- **怎么用**：搜模板 → 应用 → 站进剪影按快门
- **情绪价值**：拍照这件事，终于不用"靠等"那一张了
- **平台**：小红书/抖音为主

### 单篇② 取景器实时调参 · 所见即所得
- **牌子**：P0·差异化卖点
- **吸睛标题**：后期参数怕调毁？取景框里直接给你看成片
- **痛点**：拍完调参靠赌，翻车再翻车
- **干嘛**：调参实时生效在取景器，所见即所得
- **怎么用**：边调边看眼前成片 → 满意即按快门
- **情绪价值**："你调的就是你拿到的"，不再事后后悔
- **平台**：小红书/抖音（演示型强）

### 单篇③ 探店打卡 · 记录好店晒出去
- **牌子**：生活向
- **吸睛标题**：探到超好看的店，我用 App 记成一张海报
- **痛点**：探店拍了废了，回来什么都留不下
- **干嘛**：探店日记 + 导出海报分享
- **怎么用**：打卡 → 拍 → 套海报 → 晒社交平台
- **情绪价值**：用一张好看的照片，让别人也想打卡
- **平台**：小红书（强种草）

### 单篇④ 精选集 · 挑出好片组成九宫格
- **牌子**：整理向
- **吸睛标题**：拍了一堆选不出好看的？一个功能帮你挑
- **痛点**：照片囤照片，好片淹没
- **干嘛**：精选收藏 + 组九宫格海报分享
- **怎么用**：挑片入精选集 → 组九宫格 → 分享
- **情绪价值**："每月好片 N 张"的仪式感
- **平台**：小红书/公众号

### 单篇⑤ 自制模板 · 自己的"拍摄速通卡"
- **牌子**：进阶向
- **吸睛标题**：模板不够用？自己做一个，还能分享给闺蜜
- **痛点**：平台模板总有差临门一脚
- **干嘛**：DIY 模板 → 自用 → 分享好友/用户
- **怎么用**：定场景/姿势/参数 → 存模板 → 分享
- **情绪价值**：你的审美，也能成为别人的速通卡
- **平台**：知乎/掘金（讲方法与原理）

### 单篇⑥ 今日灵感 + 今日挑战（合本篇）
- **牌子**：养成向
- **吸睛标题**：今天不知道拍啥？它替你想好题材和挑战
- **痛点**：拿起手机，不知道拍什么
- **干嘛**：今日灵感（天气/时间/偏好推荐）+ 今日挑战（跳出舒适区）
- **怎么用**：看灵感 → 跟拍 → 打卡攒习惯
- **情绪价值**：把拍照变成上瘾的小习惯
- **平台**：小红书（轻量日更系）

### 单篇⑦ 摄影美学院 · 边拍边学
- **牌子**：学习向
- **吸睛标题**：拍照还想更懂？这里用轻松图文补课
- **痛点**：想提升审美，但不想啃理论
- **干嘛**：图文教程补构图/光线/角度
- **怎么用**：刷美学院 → 现学现拍
- **情绪价值**："原来我也能越拍越明白"
- **平台**：公众号/知乎（长内容）

## 四、单篇统一写作模板（每篇套用）

```
1. 情绪钩子（前三秒，1-2 句）→ 揪住那个"对，我就是这样"的瞬间
   —— 例："拍照想好看，先学会摆姿势？我偏不。"
2. 痛点场景化（带画面）→ 让读者点头
   —— 例："对象站得笔直，你喊'换个角度'，他一脸：啥角度？"
3. 功能是什么（一句话讲清）
   —— 例："进 App 搜关键词 → 一键套用模板 → 剪影框好构图和姿势。"
4. 3 步怎么用（短平台 3 条；长平台展开）
5. 情绪价值收尾（站在用户那一边，给承诺不涉及虚假）
   —— 例："拍照不是技术活，是被看见的普通事。"
```

## 五、合规要点（贯穿全体）

- 每个单篇讲的功能均对应用户本人真实能力，不杜撰
- 无极限词、无"免费"误导、无效果承诺
- 示例截图用 `_i2i_full/` 真实取景框图；海报用真实分享海报
- 商店链接统一替换 iOS / 华为真实地址
