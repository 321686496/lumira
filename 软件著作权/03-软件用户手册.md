# 软件用户手册

## 如画 Lumira 摄影辅助应用 V1.0.0

---

## 一、欢迎使用

### 1.1 产品简介

「如画 Lumira」是一款面向摄影爱好者的智能摄影辅助移动应用。无论你是摄影新手还是资深玩家，如画都能帮助你轻松拍摄和编辑高质量照片。

### 1.2 核心亮点

- **智能拍摄辅助**：构图叠图 + 姿势剪影 + 参数建议
- **18个场景预设**：咖啡馆、图书馆、海边、森林等
- **15种LUT滤镜**：电影、复古、日系、赛博朋克等
- **8套颜色主题**：暖米白、浓墨、胶片复古等
- **完全离线**：零网络依赖，保护隐私

### 1.3 系统要求

| 平台 | 要求 |
|---|---|
| iOS | 12.0 及以上 |
| Android | 8.0 及以上 |
| H5 | 支持getUserMedia的现代浏览器 |

## 二、快速开始

### 2.1 安装与启动

1. 从应用商店下载「如画 Lumira」
2. 点击应用图标启动
3. 首次启动时授予相机权限
4. 进入首页，开始使用

### 2.2 界面概览

```
        ╭───────────────────────────╮
        │   🏠      📚      📷      ✨      👤   │
        │  首页    模板    拍摄    灵感    我的  │
        ╰───────────────────────────╯
```

- **首页**：模板推荐、挑战任务、数据统计
- **模板**：浏览、搜索、解锁模板
- **拍摄**：进入拍摄模式（中心按钮）
- **灵感**：穿搭日记、心情标签、场景向导
- **我的**：个人中心、设置

## 三、功能使用指南

### 3.1 拍摄照片

#### 步骤一：选择拍摄方式

| 方式 | 操作 |
|---|---|
| 直接拍摄 | 点击底部中心拍摄按钮 |
| 使用模板 | 在模板库选择模板 → 点击套用 |
| 场景拍摄 | 在灵感页选择场景 → 进入拍摄 |

#### 步骤二：调整拍摄参数

| 参数 | 调整方式 |
|---|---|
| 构图线 | 自动叠加，可在设置中关闭 |
| 姿势剪影 | 自动叠加，可在设置中关闭 |
| 前后置 | 点击切换按钮 |
| 闪光灯 | 点击闪光灯图标切换模式 |
| 曝光补偿 | 滑动EV调节条 |

#### 步骤三：拍摄与保存

1. 点击快门按钮拍摄
2. 预览拍摄效果
3. 点击确认保存到相册，或点击重拍

### 3.2 使用模板

#### 浏览模板

1. 点击底部「模板」Tab
2. 浏览双列瀑布流模板列表
3. 点击分类标签筛选模板

#### 使用模板

1. 点击模板卡片进入详情
2. 查看模板信息（构图、姿势、参数、后期）
3. 点击「套用」进入拍摄模式
4. 按照模板指引拍摄

#### 创建模板

1. 在模板库点击「创建」
2. 上传姿势参考图
3. 绘制构图叠图
4. 设置相机参数
5. 设置后期参数
6. 保存为.pptpl格式

### 3.3 场景拍摄

1. 点击底部「灵感」Tab
2. 选择「场景向导」
3. 浏览18个预设场景
4. 点击场景卡片查看详情
5. 查看拍摄指南和贴士
6. 点击「去拍摄」进入拍摄模式

### 3.4 后期编辑

#### 基础调整

1. 在相册选择照片
2. 点击「编辑」进入后期模式
3. 选择调整工具：
   - 调色：亮度、对比度、饱和度、色温
   - LUT：15种色彩预设
   - 裁剪：旋转、裁剪、翻转
   - 美颜：磨皮、锐化
   - 效果：暗角、颗粒

#### 高级调整

| 工具 | 说明 |
|---|---|
| 高光 | 调整高光区域亮度 |
| 阴影 | 调整阴影区域亮度 |
| 黑点 | 调整黑场深度 |
| 清晰度 | 调整中间调对比度 |
| 自然饱和度 | 智能饱和度（肤色保护） |
| 鲜明度 | 亮部饱和度+亮度组合 |

#### 导出保存

1. 调整完成后点击「导出」
2. 选择导出质量
3. 保存到系统相册

### 3.5 主题设置

1. 进入「我的」→「设置」→「主题」
2. 选择颜色主题：
   - 暖米白（默认）
   - 浓墨
   - 胶片复古
   - 日系清新
   - 温馨粉
   - 马卡龙
   - 莫兰迪
   - 玫瑰金
3. 选择UI风格：
   - 新拟态
   - 扁平化
   - 玻璃拟态
   - 女性美学

### 3.6 相册管理

#### 浏览照片

1. 在首页点击「相册」
2. 网格浏览所有照片
3. 点击照片查看详情

#### 拍摄日记

1. 进入相册 → 「日记」
2. 时间轴视图查看拍摄记录
3. 点击日期查看当天照片

#### 月度精选

1. 进入相册 → 「月度精选」
2. 查看每月精选照片合集

## 五、常见问题

### Q1：无法启动相机？

请检查：
1. 是否已授予相机权限
2. 相机是否被其他应用占用
3. 重启应用或设备

### Q2：照片保存失败？

请检查：
1. 存储空间是否充足
2. 是否已授予存储权限

### Q3：如何导入模板？

1. 获取.pptpl格式模板文件
2. 在模板库点击「导入」
3. 选择文件导入

### Q4：如何分享照片？

1. 在相册选择照片
2. 点击「分享」按钮
3. 选择分享方式

### Q5：软件需要网络吗？

不需要。如画 Lumira 完全离线运行，所有功能均不依赖网络。
