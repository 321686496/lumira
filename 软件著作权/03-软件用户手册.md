本用户手册旨在为「如画 Lumira 摄影辅助应用 V1.0.0」（以下简称"如画 Lumira"）的最终用户提供完整、详实、可操作的功能使用说明，帮助用户快速理解软件的整体架构、运行环境、安装方式与各功能模块的操作流程。本手册适用于初次接触本软件的新用户，也可作为熟练用户查阅特定功能时的参考文档。

### 1.2 软件概述

如画 Lumira 摄影辅助应用是一款面向摄影爱好者的全平台智能摄影辅助工具，基于 Flutter 3.7+ / Dart 2.19.6 技术栈开发，支持 Android、iOS、HarmonyOS（OHOS）、Web、Windows、macOS、Linux 等多平台运行。软件采用"离线优先、零网络权限、隐私保护"的设计理念，所有数据均在本地处理，不依赖任何网络服务，最大程度保障用户隐私。

软件提供 10 大功能模块、34 个功能页面，覆盖从拍摄前的灵感激发、场景选择、模板套用，到拍摄中的构图辅助、姿势参考、参数调整，再到拍摄后的相册管理、拍摄日记、月度精选等摄影全流程需求。软件内置 18 个场景预设、15 种 LUT 滤镜、8 个免费模板与 4 个付费模板，并提供 8 套颜色主题 × 4 种 UI 风格共 32 种个性化组合供用户自由切换。

软件核心亮点包括：

- **智能拍摄辅助**：通过构图叠图、姿势剪影、相机参数面板三重辅助，帮助用户在拍摄时获得专业级的取景与构图指引。
- **多平台一致体验**：基于 Flutter 跨平台框架开发，确保各平台下的视觉风格、交互逻辑、功能表现完全一致。
- **完全离线运行**：软件启动后无需任何网络连接，所有功能（包括模板生成、LUT 应用、场景推荐）均在本地完成计算。
- **零权限收敛**：除必要的相机、存储权限外，不申请任何其他敏感权限，从架构层面保障用户隐私安全。
- **高度可个性化**：8 主题 × 4 风格的视觉组合满足不同用户的审美偏好，从新拟态到玻璃拟态、从浓墨到马卡龙均有覆盖。
- **自包含模板格式**：采用 .pptpl 自定义格式，模板文件内嵌构图坐标、姿势参考、参数配置、后期预设及 base64/image/SVG 数据，可完整离线分享与还原。
- **场景化智能推荐**：根据时间、天气、上下文智能推荐适合的拍摄场景。
- **游戏化成长体系**：每日挑战与连续打卡激励用户持续提升摄影技能。
- **多视图相册管理**：瀑布流、网格、时间轴三种视图配合智能筛选高效管理照片。
- **完整后期管线**：15 种 LUT 滤镜与多参数调色引擎协同工作，实现专业级后期。

## 二、软件安装与初始化

### 2.1 下载安装

#### 2.1.1 Android 平台安装

1. 打开设备上的官方应用商店（华为应用市场、小米应用商店、OPPO 软件商店、vivo 应用商店、应用宝等），在搜索框中输入"如画 Lumira"。
2. 在搜索结果中找到本软件，确认开发者信息后点击"安装"按钮。
3. 等待安装包下载完成（安装包大小约 35MB），系统会自动完成安装流程。
4. 安装完成后，桌面会出现"如画 Lumira"应用图标。
5. 若通过官网下载 .apk 安装包安装，需在系统设置中开启"允许安装未知来源应用"权限。

#### 2.1.2 iOS 平台安装

1. 打开 App Store，在搜索栏输入"如画 Lumira"。
2. 进入应用详情页，点击"获取"按钮并验证 Apple ID 或使用 Face ID / Touch ID 确认。
3. 等待下载完成后，桌面自动生成应用图标。
4. 首次打开时若提示"未受信任的开发者"，请前往"设置 → 通用 → VPN与设备管理"中信任开发者证书。

#### 2.1.3 HarmonyOS 平台安装

1. 打开华为应用市场，搜索"如画 Lumira"。
2. 点击"安装"按钮，等待下载与安装完成。
3. HarmonyOS 5.0 及以上版本支持纯净模式，建议保持开启以确保安装包完整性校验。

#### 2.1.4 桌面平台安装

- **Windows**：从官网下载 .msix 或 .exe 安装包，双击运行按向导完成安装。
- **macOS**：从官网下载 .dmg 镜像，拖拽至"应用程序"文件夹完成安装。首次打开时若提示"无法验证开发者"，请前往"系统设置 → 隐私与安全性"中点击"仍要打开"。
- **Linux**：从官网下载 .deb 或 .rpm 包，使用对应包管理器安装。

#### 2.1.5 Web 版使用

在支持 getUserMedia API 的现代浏览器地址栏中输入官方 Web 地址，即可直接使用，无需安装。Web 版功能与移动端基本一致，但部分平台特有的相机高级参数可能受限。

### 2.2 首次启动

1. 在设备桌面点击"如画 Lumira"应用图标启动软件。
2. 软件首先进入 splash 启动页，展示启动动画与品牌标识，同时完成内部初始化（包括数据库加载、主题配置读取、模板库索引、LUT 资源预加载等）。

## 三、界面概览

### 3.1 整体布局

如画 Lumira 采用经典的"顶部内容区 + 底部悬浮 TabBar"双区布局结构。顶部内容区根据当前所在模块动态展示对应的功能界面，底部 TabBar 采用悬浮设计，与内容区之间留有间距，呈现现代感与轻盈感。

底部 TabBar 是软件的主导航元素，包含 5 个入口，从左至右依次为：

| 序号 | Tab 名称 | 图标 | 功能定位 |
|---|---|---|---|
| 1 | 首页 | 🏠 | 模板推荐、挑战任务、数据统计、场景推荐、快捷入口 |
| 2 | 模板 | 📚 | 模板库浏览、模板详情、模板编辑、导入导出 |
| 3 | 拍摄 | 📷 | 相机取景、构图辅助、姿势参考、参数调整（中心突出按钮） |
| 4 | 灵感 | ✨ | 每日签到、心情记录、穿搭日记、场景向导 |
| 5 | 我的 | 👤 | 个人主页、设置、主题、成长体系、摄影学院、收藏集 |

其中"拍摄"按钮位于 TabBar 正中央，采用大尺寸圆形按钮设计，视觉上明显突出于其他 4 个 Tab，方便用户在任何界面下快速进入拍摄模式。

### 3.2 TabBar 交互说明

- **点击切换**：点击任一 Tab 即可切换至对应模块，切换时伴有轻微的过渡动画。
- **当前态指示**：当前所在 Tab 的图标会高亮显示，并配以底部圆点指示器。
- **悬浮设计**：TabBar 与屏幕底部保持一定距离，背景采用半透明毛玻璃效果，确保在不同主题下均能清晰辨识。
- **横屏适配**：横屏拍摄时，TabBar 自动隐藏，最大化取景画面。

### 3.3 顶部内容区

顶部内容区根据当前 Tab 动态切换，每个模块的顶部布局各有差异：

- **首页**：顶部展示用户头像、等级、连续打卡天数，下方滚动展示各功能卡片。

- **拍摄**：进入全屏取景模式，顶部叠加显示参数面板与功能按钮。
- **灵感**：顶部展示当日签到状态，下方为心情与穿搭记录入口。
- **我的**：顶部展示个人主页卡片，下方为功能列表。

## 四、核心功能使用说明

### 4.1 首页模块

#### 4.1.1 功能描述

首页是用户启动软件后默认进入的界面，承担信息聚合与快捷入口的双重作用。首页自上而下依次展示以下内容板块：

1. **模板推荐轮播**：横向滚动展示系统精选模板，每张卡片显示模板缩略图、名称、作者与适用场景标签。
2. **每日挑战**：展示当日挑战任务，包含主题、示例图、奖励内容，点击可进入挑战详情。
3. **合拍挑战**：展示合拍主题，邀请用户与好友或社区共同完成拍摄。
4. **限时免费**：展示限时免费开放的付费模板，倒计时显示剩余时间。
5. **连续打卡**：展示用户当前连续打卡天数与日历视图。
6. **数据统计卡片**：展示累计拍摄数、模板使用数、连续打卡天数、灵感记录数等数据。
7. **场景推荐**：根据当前时间、天气等上下文推荐适合的拍摄场景。
8. **快捷入口**：提供"立即拍摄""浏览模板""每日签到"等快捷操作按钮。
9. **最近拍摄**：横向滚动展示最近拍摄的照片缩略图。
10. **摄影小贴士**：每日推送一条摄影技巧或构图知识。

#### 4.1.2 操作步骤

1. 启动软件后自动进入首页，自上而下浏览各板块内容。
2. 在"模板推荐轮播"中左右滑动浏览，点击任一模板卡片进入模板详情页。
3. 点击"每日挑战"卡片进入挑战详情，查看任务要求与奖励。
4. 点击"数据统计卡片"中的任一指标可进入详细统计页面。
5. 点击"快捷入口"中的"立即拍摄"按钮，跳转至拍摄模块。
6. 点击"最近拍摄"中的任一缩略图，进入照片详情页。
7. 下拉刷新首页内容，获取最新的模板推荐与挑战任务。

### 4.2 模板模块

#### 4.2.1 功能描述

模板模块是软件的核心功能之一，提供完整的模板生命周期管理，包括模板浏览、详情查看、编辑创建、导入导出、解锁与草稿箱等功能。软件内置 8 个免费模板与 4 个付费模板，覆盖人像、风景、街拍、静物等多种拍摄主题。模板采用 .pptpl 自定义格式存储，自包含 JSON 结构，内含 base64 编码的图像、SVG 矢量数据、构图坐标、姿势参考、相机参数、后期预设等完整信息。

模板模块包含以下子页面：模板库浏览、模板详情、模板编辑器、模板导入导出、模板解锁、草稿箱、推荐模板、全部模板。

#### 4.2.2 浏览模板

1. 点击底部 TabBar 的"模板"按钮进入模板库。

3. 搜索框下方为分类标签栏，横向滑动可浏览全部分类（推荐、人像、风景、街拍、静物、夜景、胶片、清新等）。

### 4.3 拍摄模块

#### 4.3.1 功能描述

拍摄模块是软件最核心的功能模块，提供专业级的相机取景与多重辅助功能。模块包含相机预览、构图叠图叠加、姿势剪影参考、相机参数面板、横竖屏自适应、前后摄像头切换、全屏模式、场景引导页、场景管理页、场景详情页、拍摄预览页、模板预览页等 12 个子页面。

软件通过 Flutter 的 Camera 插件实现跨平台的相机访问能力，并在预览层之上叠加构图叠图层与姿势剪影层，三层叠加实时呈现专业级的取景辅助效果。

#### 4.3.2 进入取景界面

1. 点击底部 TabBar 中央的"拍摄"按钮，进入相机取景界面。
2. 软件自动调用设备后置摄像头，全屏展示实时取景画面。
3. 首次进入时若未授权相机权限，软件会引导用户前往系统设置开启权限。
4. 取景界面顶部叠加显示功能按钮栏，包括：闪光灯切换、设置、网格线开关、构图叠图开关、姿势剪影开关、参数面板开关。
5. 取景界面底部叠加显示模式切换栏（普通拍摄 / 模板拍摄 / 场景拍摄）、参数快捷调节条、快门按钮、相册入口、前后摄像头切换按钮。

#### 4.3.3 构图叠图叠加

1. 在取景界面点击顶部"构图叠图"按钮（带网格图标），开启构图叠图叠加。
2. 叠图层会在取景画面上绘制三分线、对角线、黄金比例线、安全框等构图参考线。
3. 若当前套用了模板，叠图层会额外显示模板定义的主体位置框、引导线、对齐标记。
4. 叠图层默认半透明显示，可通过双指捏合调整透明度。
5. 再次点击"构图叠图"按钮可关闭叠图层。

#### 4.3.4 姿势剪影参考

1. 在取景界面点击顶部"姿势剪影"按钮（带人形图标），开启姿势剪影叠加。
2. 软件在取景画面上叠加显示人形剪影参考，包含头、肩、肘、手、髋、膝、足等关键关节点。
3. 若当前套用了模板，剪影会按照模板预设的姿势进行姿态调整。
4. 剪影默认居中显示，可拖动调整位置，双指捏合调整大小。
5. 剪影颜色默认为半透明白色，可在设置中切换为黑色、红色、绿色等高对比度颜色。

#### 4.3.5 相机参数调整

1. 在取景界面点击顶部"参数面板"按钮，展开相机参数面板。
2. 参数面板以浮层形式展示在取景画面下方，包含以下可调节项：
   - **焦距**：通过滑块调整，范围 24mm-200mm，支持常见焦段快速切换。
   - **光圈**：通过滑块调整，范围 f/1.4 - f/16，模拟景深效果。
   - **快门**：通过滑块调整，范围 1/8000s - 30s。
   - **ISO**：通过滑块调整，范围 50 - 6400。
   - **白平衡**：选择预设（日光、阴天、白炽灯、荧光灯、自定义）或通过滑块调整色温。
   - **曝光补偿**：通过滑块调整 EV 值，范围 -3.0 - +3.0。
3. 调整任一参数后，取景画面实时反映变化效果。
4. 点击"重置"按钮可恢复默认参数。
5. 点击"保存为预设"可将当前参数组合保存为自定义预设。

### 4.4 挑战模块

#### 4.4.1 功能描述

挑战模块通过游戏化机制激励用户持续练习拍摄，提升摄影技能。模块包含每日挑战、合拍挑战、连续打卡、明日预告、挑战详情 5 个子页面。

- **连续打卡**：记录用户连续完成每日挑战的天数，达 7 天、30 天、100 天等里程碑时解锁专属成就。
- **明日预告**：提前预告次日挑战主题，方便用户准备拍摄道具与场景。
- **挑战详情**：展示挑战任务的具体要求、示例图片、奖励内容、已参与人数。

5. 提交成功后，软件展示获得的奖励（经验值 +N、成就碎片 ×1），并更新连续打卡天数。
6. 在"合拍挑战"页面可查看当前合拍主题，点击"邀请好友"通过系统分享发送邀请链接。
7. 在"连续打卡"页面查看日历视图，绿色标记为已打卡日，灰色为未打卡日。
8. 在"明日预告"页面提前查看次日主题，做好拍摄准备。

### 4.5 灵感模块

#### 4.5.1 功能描述

灵感模块是用户的创意激发与心情记录中心，包含每日签到、心情记录、穿搭日记三个核心功能，并集成了场景向导入口。模块帮助用户建立日常拍摄的习惯，同时记录拍摄之外的情绪与穿搭灵感。

#### 4.5.2 每日签到

1. 点击底部 TabBar 的"灵感"按钮进入灵感模块。
2. 顶部展示当日签到卡片，显示连续签到天数与今日签到状态。
3. 若未签到，卡片显示"点击签到"按钮；点击后弹出签到动画，展示获得的奖励（经验值、随机成就碎片）。
4. 签到完成后，卡片显示"今日已签到"状态与累计签到日历。
5. 连续签到 7 天、30 天、90 天等节点会触发额外奖励。

#### 4.5.3 心情记录

1. 在灵感模块点击"心情记录"卡片进入心情记录页面。
2. 页面以时间轴形式展示用户的所有心情记录，按日期分组。
3. 点击右下角"新建"按钮，进入心情记录编辑页。
4. 选择当前心情（开心、平静、思考、忧郁、激动、放松等 12 种预设心情）。
5. 输入心情描述文字（可选），添加一张配图（可选，可从相册选择或即时拍摄）。

| 序号 | 风格名称 | 视觉特征 |

### 5.4 主题切换方法

1. 进入"我的 → 主题"页面。
2. 顶部预览区展示当前主题与风格的组合效果。
3. 下方左侧为颜色主题选择区，横向滚动展示 8 套主题的预览卡片，每张卡片显示该主题的代表色块与名称。
4. 下方右侧为 UI 风格选择区，纵向排列 4 种风格的预览卡片。
5. 点击任一颜色主题卡片，预览区即时切换为该主题效果，全应用界面同步更新。
6. 点击任一 UI 风格卡片，预览区即时切换为该风格效果，按钮、卡片、列表等元素同步更新。
7. 用户可自由组合任一颜色主题与任一 UI 风格，共 32 种组合。
8. 选择满意后点击"应用"按钮确认保存，或点击"重置"恢复默认主题（暖米白 + 新拟态）。

## 六、常见问题

### 6.1 Q1：软件是否需要联网才能使用？

不需要。如画 Lumira 采用"离线优先、零网络权限"的设计理念，软件启动后无需任何网络连接即可使用全部核心功能，包括模板浏览与编辑、相机拍摄、构图叠图、姿势剪影、LUT 滤镜应用、相册管理、挑战打卡、心情与穿搭记录、主题切换等。所有数据均在本地处理与存储，最大程度保护用户隐私。仅在以下可选场景需要网络：分享内容至第三方应用、导入导出文件至云盘、邀请好友时生成邀请链接。

### 6.2 Q2：相机无法启动怎么办？

请按以下步骤排查：

1. 确认是否已授予软件相机权限。前往系统"设置 → 应用管理 → 如画 Lumira → 权限管理"中检查相机权限是否已开启。
2. 确认相机是否被其他应用占用。关闭其他正在使用相机的应用（如视频会议、其他相机软件）后重试。
3. 完全退出软件后重新启动，或重启设备。
4. 检查系统版本是否符合要求（Android 8.0+、iOS 12.0+、HarmonyOS 5.0+）。
5. 若问题持续存在，请在"我的 → 设置 → 关于 → 意见反馈"中提交问题描述与设备型号信息。

### 6.3 Q3：拍摄的照片保存到哪里？

拍摄的照片默认保存至设备的系统相册中，路径为：

- **Android**：/Pictures/如画 Lumira/
- **iOS**：系统相册"如画 Lumira"相簿
- **HarmonyOS**：/Pictures/如画 Lumira/
- **桌面平台**：用户目录下的 Pictures/如画 Lumira/ 文件夹

照片文件名格式为"lumira_yyyyMMdd_HHmmss.jpg"，同时软件会在本地数据库中记录照片的元数据（拍摄参数、模板信息、场景信息等）用于相册管理与拍摄日记。

### 6.4 Q4：如何创建和分享自定义模板？

**创建模板**：

1. 进入"模板"Tab，点击右上角"创建"按钮进入模板编辑器。
2. 依次完成构图、姿势、参数、场景、后期五个维度的配置。
3. 编辑过程中可随时保存草稿。
4. 完成后点击"保存"按钮，输入模板信息。

**分享模板**：

1. 在模板详情页点击"分享"按钮。
2. 选择"导出为文件"，软件将模板打包为 .pptpl 格式。
3. 通过系统分享发送给好友，或保存至云盘。

**导入模板**：

1. 在模板库点击"导入"按钮。
2. 选择 .pptpl 文件即可完成导入。

### 6.5 Q5：如何切换主题与 UI 风格？

1. 进入"我的 → 主题"页面。
2. 在 8 套颜色主题中选择喜欢的主题。
3. 在 4 种 UI 风格中选择喜欢的风格。
4. 点击"应用"按钮保存设置。
5. 全应用界面即时更新，无需重启软件。

软件支持 8 × 4 = 32 种主题组合，用户可根据心情与场景自由切换。切换主题不会影响已拍摄照片与已创建模板等数据。

### 6.6 Q6：付费模板如何解锁？

1. 在模板库中找到带有锁形图标的付费模板。
2. 点击进入模板详情页，预览部分内容。
3. 点击底部"解锁"按钮，弹出解锁确认对话框。
4. 确认后通过应用内支付（Apple Pay / Google Pay / 华为 Pay 等，根据平台而定）完成支付。
5. 支付成功后模板永久可用，可在"我的 → 我的模板"中查看授权状态。
6. 解锁后的模板支持离线使用，无需再次联网验证。

### 6.7 Q7：软件占用存储空间过大怎么办？

1. 进入"我的 → 设置 → 通用 → 缓存清理"，清理临时缓存数据。
2. 在相册中删除不需要的照片，或导出至电脑后从软件中删除。
3. 删除不再使用的模板草稿与拍摄套件。
4. 检查"我的 → 我的模板"中的导入模板数量，删除不常用模板。
5. 定期清理拍摄日记中过期的内容。
6. 若仍占用过大空间，可使用"数据备份"功能将数据导出后重置软件。

### 6.8 Q8：如何备份数据？

1. 进入"我的 → 设置 → 通用 → 数据备份"。
2. 选择需要备份的内容：拍摄数据、模板、拍摄日记、心情记录、穿搭日记、收藏集、成长记录。
3. 点击"开始备份"，软件将所选内容打包为 .lumira-backup 格式的备份文件。
4. 选择备份文件保存位置（本地存储或云盘）。
5. 需要恢复时，进入"数据恢复"，选择备份文件即可。

备份文件采用本地加密存储，仅软件本身可读取，保障数据安全。
