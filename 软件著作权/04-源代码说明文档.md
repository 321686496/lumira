## 二、核心代码模块说明

### 2.1 类型定义（types/template.ts）

**功能**：定义整个应用的核心数据类型

**主要类型**：

| 类型名 | 说明 | 关键字段 |
|---|---|---|
| `PhotoTemplate` | 完整拍照模板 | meta, composition, pose, camera, sceneGuide, postProcess |
| `ScenePreset` | 场景预设 | id, name, filter, vibe, description, tips |
| `CameraParams` | 相机参数 | exposureCompensation, iso, shutterSpeed, whiteBalance |
| `PostProcess` | 后期参数 | cropRatio, color, smoothStrength, sharpen, lut |
| `Composition` | 构图信息 | overlayType, subjectFrame, opacity, aspectRatio |
| `Pose` | 姿势参考 | silhouette, position, scale, rotation |
| `ShootKit` | 拍摄组合 | sceneId, templateId, overrides |
| `LocalPhoto` | 本地照片 | dataUrl, sceneId, templateId, mood, lut |

### 2.2 相机控制（composables/useCamera.ts）

**功能**：跨平台相机控制组合式函数

**核心方法**：

| 方法 | 功能 | 平台适配 |
|---|---|---|
| `startPreview()` | 启动相机预览 | H5: getUserMedia / App: CameraContext |
| `stopPreview()` | 停止预览 | 统一接口 |
| `capture()` | 拍照并烘焙 | H5: 截帧+Canvas / App: takePhoto+Canvas |
| `switchCamera()` | 切换前后置 | H5: 重新获取流 / App: 切换 |
| `setFlash()` | 设置闪光灯 | H5: MediaTrackConstraints / App: 原生 |
| `setIso()` | 设置ISO | H5: MediaTrackConstraints / App: CSS滤镜 |
| `release()` | 释放资源 | 统一接口 |

### 2.3 图像烘焙引擎（utils/bakeCanvas.ts）

**功能**：Canvas像素级图像处理核心

**处理流程**：

```
输入图像 → 绘制到Canvas → CSS滤镜链 → 像素级LUT → 暗角 → 颗粒 → 锐化 → 导出
```

**核心函数**：

| 函数 | 功能 |
|---|---|
| `bakePhotoForCanvas()` | 主烘焙函数，应用所有效果 |
| `buildCssFilter()` | 构建CSS滤镜字符串 |
| `applyLutPixel()` | 像素级LUT色彩映射 |
| `applyVignette()` | 径向渐变暗角 |
| `applyGrain()` | 随机噪声颗粒 |
| `applySharpen()` | 卷积核锐化 |

## 六、代码特色

### 6.1 类型安全

- 全量TypeScript开发，禁用any类型
- 严格的Props/Emits类型签名
- 跨层数据传递使用TypeScript接口

### 6.2 架构清晰

- 遵循Harness Engineering范式
- 骨架优先、接口驱动、规格验证
- 单向数据流，组件不可直接调用Service

### 6.3 跨平台适配

- uni-app框架，一套代码多平台运行
- 条件编译处理平台差异
- 统一的Composable接口封装

### 6.4 性能优化

- Canvas离屏渲染
- CSS滤镜链式组合
- 仅动画transform与opacity
- 列表交错动画延迟
