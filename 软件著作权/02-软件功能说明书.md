## 一、概述

### 1.1 软件简介

「如画 Lumira」是一款面向摄影爱好者的智能摄影辅助移动应用，基于uni-app跨平台框架开发，支持iOS、Android和H5平台。软件通过提供构图叠图、姿势剪影、场景预设、模板系统、后期处理等功能，帮助用户轻松拍摄和编辑高质量照片。

### 1.2 设计原则

| 原则 | 说明 |
|---|---|
| 编辑式留白 | 内容区大量宏观留白，呼吸感优先 |
| 内容即界面 | 照片/取景器为主角，UI控件退让至边缘或悬浮层 |
| 字体对比 | Serif标题 + Sans正文，强对比建立层级 |
| 悬浮层级 | Tab栏、快门、参数条以悬浮形式浮于内容之上 |
| 单点缀色 | 品牌金仅用于选中态、关键CTA、当前模板标记 |

#### 2.3.1 功能概述

拍摄模块是产品的核心功能，提供取景器、构图叠图、姿势剪影、参数面板、快门拍摄等功能。

#### 2.3.2 功能列表

| 功能编号 | 功能名称 | 功能描述 |
|---|---|---|
| CAPT-001 | 取景器 | 全屏实时相机预览，支持H5/App/小程序多平台 |
| CAPT-002 | 构图叠图 | 叠加三分法/黄金比例/对角线/引导线/网格等构图参考线 |
| CAPT-003 | 姿势剪影 | 叠加姿势剪影参考，支持内置SVG库和自定义导入 |
| CAPT-004 | 参数面板 | 显示当前生效的相机参数（水平仪、EV、WB等） |
| CAPT-005 | 快门拍摄 | 触发拍照，支持H5截帧和App原生拍照 |
| CAPT-006 | 拍摄预览 | 拍摄后立即预览，支持重拍和确认保存 |
| CAPT-007 | 前后置切换 | 切换前后置摄像头 |
| CAPT-008 | 闪光灯控制 | 关闭/开启/自动/常亮四种模式 |
| CAPT-009 | ISO调节 | 通过MediaTrackConstraints或CSS滤镜实现 |
| CAPT-010 | 图像烘焙 | Canvas像素级处理，应用所有后期效果后导出 |

#### 2.3.3 拍摄流程

```
用户点击拍摄按钮
    ↓
启动相机预览（getUserMedia / CameraContext）
    ↓
加载模板叠图（构图线 + 姿势剪影）
    ↓
用户调整参数（EV/ISO/WB/闪光灯）
    ↓
按下快门
    ↓
截帧/拍照 → Canvas烘焙 → 生成dataURL
    ↓
预览页面（重拍/确认保存）
    ↓
保存到相册
```

#### 2.3.4 图像烘焙算法

图像烘焙是核心算法，流程如下：

1. **创建Canvas**：根据输出尺寸创建离屏Canvas
2. **绘制原图**：将视频帧/图片绘制到Canvas
3. **应用CSS滤镜链**：亮度→对比度→饱和度→色温→色调
4. **像素级处理**：遍历像素应用LUT色彩映射
5. **暗角效果**：径向渐变暗角
6. **颗粒效果**：随机噪声叠加
7. **锐化**：卷积核锐化处理
8. **导出**：canvas.toDataURL()导出为JPEG

## 四、性能目标

| 指标 | 目标值 | 测量方式 |
|---|---|---|
| 相机启动 | < 1s | 从点击Tab到取景器画面 |

## 五、安全与合规

- 零网络权限设计（不声明INTERNET权限）
