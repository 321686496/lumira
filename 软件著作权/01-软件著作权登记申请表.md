## 二、软件用途和技术特点

### 2.1 软件用途

「如画 Lumira」是一款面向摄影爱好者的智能摄影辅助移动应用，核心功能包括：

1. **智能拍摄辅助**：提供构图叠图、姿势剪影参考、相机参数建议，帮助用户拍摄专业级照片
2. **场景化推荐**：内置18个场景预设，根据光线、环境、情绪智能推荐拍摄方案
3. **模板化创作**：支持.pptpl格式拍照模板的创建、导入、编辑与套用
4. **后期处理**：提供调色、LUT滤镜、磨皮、锐化、暗角、颗粒等后期编辑功能
5. **相册管理**：支持照片浏览、分类、日记记录、月度精选等功能
6. **个性化主题**：提供8套颜色主题与4种UI风格，满足用户个性化需求

### 2.2 技术特点

| 技术维度 | 说明 |
|---|---|
| **开发框架** | uni-app（Vue3 + TypeScript） |
| **目标平台** | iOS / Android / H5 跨平台 |
| **编程语言** | TypeScript（前端）、SCSS（样式） |
| **架构模式** | Harness Engineering（骨架优先、接口驱动、规格验证） |
| **核心算法** | Canvas像素级图像处理、LUT色彩映射、CSS滤镜链式组合 |
| **数据存储** | 本地SQLite + 文件系统（零网络权限设计） |
| **渲染技术** | Canvas 2D 实时取景器渲染 + 离屏Canvas图像烘焙 |
| **设计系统** | CSS Variables设计Token系统，支持动态主题切换 |

### 2.3 创新点

1. **场景氛围引擎**：独创的场景预设系统，将光线方向、拍摄距离、最佳时间、情绪氛围融为一体，提供沉浸式拍摄引导
2. **模板烘焙技术**：基于Canvas的跨平台图像实时烘焙引擎，支持亮度/对比度/饱和度/色温/LUT/暗角/颗粒/锐化/磨皮等效果的实时预览与导出
3. **新拟态主题系统**：8套颜色主题 × 4种UI风格的矩阵式个性化方案，支持运行时动态切换
4. **离线优先架构**：全功能零网络依赖，保护用户隐私，所有数据处理在本地完成
