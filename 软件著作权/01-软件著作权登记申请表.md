## 二、软件用途和技术特点

### 2.1 软件用途

「如画 Lumira 摄影辅助应用 V1.0.0」（以下简称「如画 Lumira」）是一款面向摄影爱好者与移动影像创作者的跨平台智能摄影辅助应用，基于 Flutter 框架开发，一次编写即可运行于 Android、iOS、HarmonyOS（OHOS）、Web 及桌面（Windows、macOS、Linux）多端环境。其核心用途包括：

1. **智能拍摄辅助**：在取景器上叠加构图参考线、姿势剪影、参数面板，实时引导用户完成专业级拍摄
2. **场景化推荐**：内置 18 个场景预设（咖啡馆、图书馆、海边、森林、城市等），根据光线、环境、情绪推荐拍摄方案
3. **模板化创作**：支持 `.pptpl` 自包含 JSON 模板格式，支持模板浏览、详情、编辑、导入、解锁、草稿与推荐
4. **后期影像处理**：提供 15 种 LUT 滤镜、调色引擎、暗角、颗粒、锐化等 GPU 加速后期效果
5. **相册与日记管理**：支持照片浏览、详情查看、拍摄日记、月度精选等影像资产组织能力
6. **挑战与激励体系**：每日挑战、合拍挑战、连续打卡、灵感签到、心情穿搭日记等用户成长机制
7. **个性化定制**：8 套颜色主题 × 4 种 UI 风格矩阵式个性化方案，运行时动态切换
8. **零网络隐私保护**：离线优先架构，全功能零网络依赖，所有数据处理在本地完成

### 2.3 创新点

1. **Flutter 一次编写多端运行**：基于 Flutter 3.7+ 与 Dart 2.19.6，单一代码库同时覆盖 Android、iOS、HarmonyOS、Web 及桌面六大平台，相较传统跨平台方案显著降低多端维护成本
2. **HarmonyOS（鸿蒙）原生适配**：通过 CPF-Flutter 3.7 兼容版本与 permission_handler 鸿蒙适配，实现国产 HarmonyOS（OHOS）系统的相机、权限、相册、文件系统全链路适配
3. **Riverpod + GoRouter 现代化架构**：采用 flutter_riverpod 不可变状态管理与 go_router 声明式路由组合，34 个路由严格 1:1 对应原 uni-app pages.json 配置，确保迁移一致性
4. **Feature-first 分层架构**：app / core / features / shared 四层架构设计，10 个 feature 模块（splash、home、capture、templates、challenge、inspiration、gallery、profile、scenes、shootkit）解耦清晰，便于扩展与测试
5. **GPU 加速图像处理管线**：gpu_image + image 双引擎协同，支持 15 种 LUT 滤镜（电影、复古、日系、赛博朋克等）的实时预览与导出
6. **.pptpl 自包含模板格式**：独创 JSON 模板格式，元信息、构图、姿势、相机参数、场景指南、后期参数、base64/image/SVG 数据全部内嵌，零网络依赖即可分享与导入
7. **场景氛围引擎**：18 个场景预设将光线方向、拍摄距离、最佳时间、情绪氛围融为一体，提供沉浸式拍摄引导
8. **矩阵式主题系统**：8 套颜色主题（warmWhite/ink/retro/fresh/cozy/macaron/morandi/rosegold）× 4 种 UI 风格（neumorphic/flat/glass/female）共 32 种视觉组合，运行时动态切换
9. **离线优先隐私架构**：全功能零网络依赖，所有数据处理在本地 sqflite 数据库与文件系统完成，从架构层面保障用户隐私
10. **完善的测试体系**：41 个测试文件约 10,606 行测试代码，与 101 个业务文件约 34,691 行代码形成 1:3 测试代码比，确保应用质量
