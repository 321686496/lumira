# 姿势图反侵权批量编辑

## 用途与触发时机

从网上看到喜欢的拍照姿势想做模板,但害怕侵权;AI 直接生成姿势图又太假。本技能对**已有姿势参考图**做人脸改换(完全认不出是同一个人)+ 统一符合场景的衣着,产出可直接用于模板制作的单张成片。

**触发**: 用户给出一组人物图片(≥1 张)并表达"换脸防侵权 / 修改面部/统一衣着/做成姿势模板"等意图时调用。

## 运行前提

- API Key 环境变量(或 `--api-key`)已配置：默认引擎 `qwen3pro` 走 `MASS_API_KEY`；`--engine gpt2k` 走 `HAPI_API_KEY` —— 复用项目 `scripts/gpt_image2.py` 的 hapi 中转。
- Python 3 + Pillow。裁剪依赖 Pillow,`gpt_image2` 由本技能脚本动态 import 项目 `scripts/gpt_image2.py`。

## 目录

```
skills/anti-infringement-pose-edit/
├── SKILL.md
└── scripts/
    ├── run_batch_edit.py   # 主编排: 分批→锚点→调 hapi→裁剪→回退
    └── crop_grid.py        # 宫格智能识别与裁剪(1x2/1x3/2x2 及竖排镜像)
```

## 生图引擎与单次上限

`--engine` 决定平台/模型/单次输入图片上限（默认 `qwen3pro` = `mass` / `qwen-image-3.0-pro` / 3 张；`gpt2k` = `hapi` / `gpt-image-2.5-sunburst-2k` / 4 张），`--max-per-call` 可覆盖。

分批与布局规则：首批最多「上限」张（无锚点）；后续每批「上限-1」张目标 + 1 张衣着锚点；批内只剩 1 张时走单图编辑。宫格布局按批内张数与模板比例动态选择（1 张无宫格 / 2 张 1x2 或 2x1 / 3 张 1x3 或 3x1 / 4 张 2x2）。

裁剪出的每格会归一化到统一的目标像素（短边 768、比例 = 模板比例），因此所有成片尺寸完全一致。
另有 `--no-grid`：完全不做宫格打包，每张输入图单独跑一次单图编辑（渠道对多图输入会上游超时时使用）。

## 执行流程

1. **分批**: 按 `--engine` 推导的单次上限切分（默认 `qwen3pro` 上限 3；`--max-per-call` 可覆盖）, 次序保持输入顺序。
   - 第一批: ≤4 张目标图(无锚点);
   - 后续批: 每批 `max_per_call-1` 张目标图 + 1 张"衣着锚点"参考图(首批首张成片), 用于统一衣着。
   - 例: 9 张 → `[4] + [3+锚] + [2+锚]`, 仍是 3 次调用。
2. **调用**: 每批通过 hapi `/images/edits` 一次发出目标图(锚点批次再追加锚点图), 提示词要求模型把每张修改结果按批内张数与模板比例动态选择的宫格布局排成一张图（1x2 / 1x3 / 2x2 及竖排镜像）(左上→右上→左下→右下对应输入顺序, 格间留边框)。
3. **裁剪**: `crop_grid.py` 按"贴合全局最小方差的细白分隔线"定位切分线——在中央带内取全局最小方差位置, 只用绝对容差 `SEP_TOL=2` 向其两侧做近邻扩展(不再用宽松的相对阈值把海水/天空等平坦内容误判成分隔带), 若扩展过宽则退化为窄切以免切点跑进内容深处; 分隔线定位使用约 `sh//100` 的小平滑窗口以保住 ~6px 细白线(20px 平滑会把它抹平导致切点跑偏)。每格切出后再做"均质边净化"(`_purge_uniform_edges`, 上限 30px、std<4), 只清掉格子四周接近纯色/纯白的均质边缘(残留白线/蓝条), 内容边因方差高不会被裁。对干净 2x2 宫格, 可裁出规整近方形、无白线/蓝条/邻格串入的单格; 无分隔时仍退化为均分, 裁不干净的自动单图回退。
4. **回退**: 某格空白/低质, 或在锚点批次被误渲染——对该目标图单独跑一次单图编辑兜底, 保证每张必有输出。
5. **输出**: `--out` 下生成 `out1.png...outN.png`, 与输入顺序一一对应; 打印输入→输出映射与缺失清单。

## 用法

```bash
# 基本(9 张示例)
python scripts/run_batch_edit.py a.jpg b.jpg c.jpg d.jpg e.jpg f.jpg g.jpg h.jpg i.jpg \
    --out ./outputs

# 显式覆盖引擎推导的上限
python scripts/run_batch_edit.py 1.png 2.png 3.png 4.png 5.png --max-per-call 4 --out ./o

# 指定引擎(走 hapi, 单次上限 4)
python scripts/run_batch_edit.py 1.png 2.png 3.png 4.png 5.png --engine gpt2k --out ./o

# 指定模板宽高比(影响宫格布局与成片尺寸)
python scripts/run_batch_edit.py 1.png 2.png 3.png 4.png --ratio 3:4 --out ./o

# 只预览分批/锚点计划, 不调接口
python scripts/run_batch_edit.py img1.jpg img2.jpg ... --dry-run

# 保留中间四宫格, 便于排查裁剪
python scripts/run_batch_edit.py ... --keep-grids
```

## 关键提示词

默认编辑提示词(可用 `--prompt` 覆盖):

> 修改一下这些图中人物的面部，变得更精致，更有辨识度；优化衣着，使其与场景更贴合；仅修改人物面部，使其完全看不出与原图是同一个人，以避免侵权；并统一这几张图中人物的衣着。

自动叠加(多批次): 要求按该批次的动态布局输出、格间留边框、顺序对应输入、保持原姿势只改面部与衣着。
锚点批次再追加: 说明最后一张是"衣着锚点参考图", 仅参考服饰风格、不渲染进网格。

## 已知假设与局限

- 模型输出不保证是规整宫格 → 用智能裁剪缓解, 裁不干净自动单图回退。
- 格子顺序依赖模型遵守输入顺序 → 按读取顺序映射, 数量/内容异常会触发回退。
- 锚点占用一个"每批≤4"槽位, 因此后续批次目标图上限为 `max_per_call-1`。
- 使用自定义 `--prompt` 时锚点说明不会自动叠加, 需自行在提示词里注明锚点图(仅参考衣着、输出进网格)。
