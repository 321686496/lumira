多平台图片生成 / 编辑

支持 HAPI gpt-image2、MaaS（mass.hzxmfg.com）、千问 AI（按量付费 / Token Plan）多个平台，在前端一键切换。
先启动服务：python gpt_image2.py --server，然后在下方输入对应平台的 API Key（自动按平台保存在浏览器 localStorage，随请求经本地脚本代理转发，不会直接暴露给第三方页面）。

平台 必选

API Key 按平台持久化

处理模式 第一步

编辑模式可传入多张参考图；文生图模式不需要上传图片。各平台对多图/多输出数量支持不一，以平台文档为准。

提示词 第二步

参考图片 第三步 · 可多选

点击选择图片，或将图片拖拽到此处
支持一次选择多张

多图处理方式 第四步

一次处理（多图合并）
全部参考图放入同一个请求，模型综合所有图片生成
批量处理（逐图处理）
每张参考图单独发一次请求，各自生成
当前 1 张图，一次处理与批量处理效果相同。

输出尺寸 第五步

或自定义
根据参考图宽高自动换算合法尺寸（边长 ≤ 3840、16 的倍数、总像素 655360~8294400）。

多任务并发 一次提交多个提示词

生成结果

结果图片保存在脚本同目录 results/ 下 · 服务端日志可查看完整请求信息
